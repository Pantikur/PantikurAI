# 🌟 Wuglarst — Полное Руководство

## 🎯 Что такое Wuglarst

**Wuglarst** — это автономный сервер для наблюдения за работой 13 ИИ-учёных (12 девочек + Сидни) в реальном времени.

### Ключевые особенности

- ✅ **Постоянная работа 24/7** — сервер работает даже когда вы выключили компьютер
- ✅ **Автозапуск** — запускается автоматически при старте Windows
- ✅ **13 девочек** — полная поддержка Сидни с 8 движками
- ✅ **WebSocket** — обновления в реальном времени
- ✅ **REST API** — полный интерфейс для управления
- ✅ **Автосохранение** — состояние сохраняется каждые 5 минут
- ✅ **Автосброс** — перезапуск при падении
- ✅ **Визуальный интерфейс** — красивая веб-панель

## 🚀 Быстрый Старт

### 1. Установка

```bash
# Перейдите в папку Wuglarst
cd Wuglarst

# Запустите установку
python setup_autonomous.py
```

### 2. Запуск

```bash
# Автономный режим (рекомендуется)
python daemon.py start

# Или простой запуск
python server_autonomous.py
```

### 3. Проверка

Откройте браузер и перейдите на:
```
http://localhost:8001
```

## 🎮 Сидни — 13-я Девочка

Сидни отвечает за создание и поддержку полного игрового движка:

### 8 Движков

1. **🎨 Графический** — 2D/3D рендерер, PBR, текстуры, освещение
2. **⚙️ Физический** — гравитация, столкновения, разрушения
3. **🔊 Аудиодвижок** — 3D звук, музыка, DSP эффекты
4. **🎭 Анимация** — скелетная, морфинг, физика волос/одежды
5. **🤖 ИИ** — NPC поведение, навигация, принятие решений
6. **🌐 Сеть** — мультиплеер, репликация, синхронизация
7. **📜 Скрипты** — Lua/Python, node-based визуальное программирование
8. **🏗️ Редактор** — WYSIWYG уровни, ландшафт, префабы

### Автономность

- **Уровень:** L3 (Полная)
- **Характер:** Перфекционист | Инноватор | Аналитик | Командир | Творец
- **Знания:** 12 направлений, уровни 0-5
- **Саморазвитие:** Непрерывный цикл обучения

## 🏗️ Установка на Windows

### Вариант 1: Автоматический

```bash
cd Wuglarst
python setup_autonomous.py
```

### Вариант 2: Ручной

1. Установите Python 3.11+
2. Установите зависимости:
   ```bash
   pip install fastapi uvicorn pydantic
   ```
3. Запустите:
   ```bash
   python daemon.py install
   python daemon.py start
   ```

### Вариант 3: Через Task Scheduler

1. Откройте **Task Scheduler**
2. Создайте задачу:
   - **Trigger:** At startup
   - **Action:** Start a program
   - **Program:** `python`
   - **Arguments:** `Wuglarst\daemon.py start`
   - **Start in:** `C:\path\to\Pantikur`

## 🔌 Интеграция с Сидни

### Автоматическая

Сидни автоматически подключается к Wuglarst:

```python
from sidney import SidneyCore

sidney = SidneyCore()
sidney.initialize()  # Автоподключение к Wuglarst
sidney.start()
```

### Ручная

```python
from sidney.wuglarst_integration import WuglarstClient

client = WuglarstClient()

# Обновить статус
client.update_status(
    status="working",
    current_task="Цикл 42"
)

# Подключиться к девочкам
sisters = client.connect_to_sisters()
```

## 📞 Решение проблем

### Сервер не запускается

```bash
# Проверьте порт
netstat -ano | findstr :8001

# Освободите порт
taskkill /F /PID <PID>
```

### Сидни не подключается

```bash
# Проверьте Wuglarst
curl http://localhost:8001/health

# Перезапустите
python daemon.py restart
```

### Данные не сохраняются

```bash
# Создайте директорию
mkdir data\wuglarst
```
