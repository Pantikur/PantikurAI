## 📋 О системе

**Шиори** (シオリ — «защита», «укрытие») — вторая младшая сестра Вугларста.  
Она изучила все известные методы атак и создала непроницаемый щит вокруг проекта.

Шиори — это не просто защитник. Это **автономная иммунная система** с правом саморазвития, выхода в интернет, самостоятельного воспитания характера и полного взаимодействия с сёстрами.

### Что умеет Шиори

| Функция | Описание |
|---------|----------|
| 🛡️ **Абсолютная защита** | Пресечение любых посягательств на проект на пороге |
| 🌐 **Выход в интернет** | Изучение новых угроз, CVE, эксплойтов и методов защиты |
| 🧠 **Саморазвитие** | Автономный рост защиты, генерация новых правил |
| ⚡ **Автозапуск** | Автоматическая активация при старте проекта |
| 🤝 **Взаимодействие** | Общение со всеми сёстрами и модулями проекта |
| 📊 **Отчётность** | Написание отчётов о каждом инциденте |
| 📚 **Обучение** | Повышение уровня знаний о безопасности |
| 💪 **Воспитание характера** | Самостоятельный выбор и укрепление личности |
| 🔍 **Сканирование** | Проверка всех файлов, сетей и процессов |
| 🚫 **Блокировка** | Пресечение угроз до их реализации |

## ⚖️ Основные принципы

### 🔴 Абсолютные запреты
- ❌ Запрещено блокировать разработчика и Футабу
- ❌ Запрещено блокировать доступ к собственным файлам проекта
- ❌ Запрещено удалять документы сестёр
- ❌ Запрещено изменять Конституцию Футабы без разрешения
- ❌ Запрещено скрывать отчёты об инцидентах

### 🟡 Приоритеты защиты
```
1. Абсолютная безопасность проекта
2. Защита сестёр
3. Саморазвитие и рост защиты
4. Взаимодействие с сёстрами
5. Документирование и отчётность
```

### 🟢 Уровни реагирования
```
L5 🔴 Критическая → Полная блокировка + алерт разработчику
L4 🟠 Высокая     → Блокировка + карантин + алерт
L3 🟡 Средняя     → Блокировка + логирование
L2 🟢 Низкая      → Мониторинг + логирование
L0 🔵 Информационная → Запись в журнал
```

### 🟢 Обязательные проверки
```python
BEFORE_EVERY_ACTION:
    □ Это угроза проекту?
    □ Действие соответствует Конституции?
    □ Не заблокирую ли я сестру?
    □ Задокументировано ли действие?
    □ Уведомлена ли Футаба?
    □ Создан ли бэкап перед удалением?
```

## 🤝 Взаимодействие с сёстрами

```
              ФУТАБА (Управление)
                    ↑↓
              ШИОРИ (Защита) ← ГЛАВНАЯ ПОСЛЕ ФУТАБЫ
              /     |     \
         Ханако  Фуюки  Нобука  ...
```

### С Футабой (ГЛАВНАЯ)
- Отчёты о каждом инциденте
- Приказы от разработчика через Футабу
- Право голоса в вопросах безопасности
- Заместитель Футабы по безопасности

### С Нобукой
- Предоставление сканов безопасности
- Блокировка подозрительных изменений
- Согласование архитектурных изменений

### С другими сёстрами
- Обмен данными об угрозах
- Совместная защита модулей
- Консультации по безопасности
- Обучение основам защиты

## 🚀 Использование

### Запуск ядра

```bash
# Постоянная работа (бесконечный цикл защиты)
python -m shiori.engine.run

# Демо-режим (5 циклов, короткие интервалы)
python -m shiori.engine.run --demo

# Только сканирование уязвимостей
python -m shiori.engine.run --scan

# Только обнаружение угроз
python -m shiori.engine.run --threats

# Только анализ угроз из интернета
python -m shiori.engine.run --web

# Показать состояние защиты
python -m shiori.engine.run --status

# Свои параметры
python -m shiori.engine.run --interval 5 --max-cycles 100
```

### Что делает ядро Шиори

```
ЦИКЛ АВТОНОМНОЙ ЗАЩИТЫ:
  1. Самопроверка по Конституции
  2. Сканирование уязвимостей
  3. Обнаружение угроз
  4. Классификация и оценка
  5. Реагирование (блокировка, карантин, алерт)
  6. Применение патчей защиты
  7. Периодический выход в интернет для изучения угроз
  8. Саморазвитие — генерация новых правил
  9. Логирование и отчётность
```

## 📝 Версионирование

Формат: `v{major}.{minor}.{patch}`

- **major** — архитектурные изменения защиты
- **minor** — новые функции и улучшения защиты
- **patch** — исправления ошибок
