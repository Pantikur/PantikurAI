## 📋 О системе

**Шиори** — это автономная иммунная система, защищающая нейросеть Вугларст от внешних угроз, внутренних аномалий и несанкционированного вмешательства.

Название «Шиори» (яп. 紫苑 — астра) символизирует бдительность и защиту.

## ⚙️ Автономное ядро (Python)

Шиори имеет исполняемое ядро постоянной работы в `shiori/engine/`.

### Запуск

```bash
# Постоянная работа (бесконечный цикл защиты)
python -m shiori.engine.run

# Демо-режим (5 циклов, короткие интервалы)
python -m shiori.engine.run --demo

# Только сканирование угроз
python -m shiori.engine.run --scan

# Посмотреть текущее состояние
python -m shiori.engine.run --status

# Свои параметры
python -m shiori.engine.run --interval 2 --max-cycles 100
```

### Что делает ядро

```
ЦИКЛ ЗАЩИТЫ:
  1. Сканирование уязвимостей
  2. Обнаружение угроз
  3. Оценка и классификация
  4. Реагирование (блокировка, карантин, алерт)
  5. Применение патчей
  6. Логирование и отчётность
  7. Периодически — саморазвитие защиты
```
