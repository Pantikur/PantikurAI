# AGENTS.md

## Роль этого файла

Этот файл — контекст для AI-ассистентов (Koda, Claude, Copilot и т.п.), работающих в этом репозитории. Он дополняет `README.md` практическими правилами.

## Проект

**Pantikur ChatBot** — нейросетевой чат-бот с долгосрочной памятью и автообучением (PyTorch + FastAPI). Стек: Python 3.11, PyTorch, Transformers, FastAPI, WebSocket, Docker.

## Как устроен репозиторий

- `main.py` — FastAPI-приложение, WebSocket-эндпоинт.
- `Wuglarst/src/` — ядро чат-бота (модель, токенизатор, культурные отсылки).
- `utils/` — генераторы training-данных, парсеры книг, веб-поиск.
- `data/` — диалоги, обучающие пары, кэш знаний (JSON/JSONL).
- `models/` — Qwen2.5-3B, веса.
- `scripts/` — скрипты автобучения (`auto_learn_cycle.py`, `init_knowledge_system.py`).

## Ключевые правила

1. Модульность — чини маленькие кусочки; не рефактори всё сразу.
2. Минимальные диффы: не таскай файлы по репозиторию без запроса.
3. Китайский язык: это чат-бот на русском языке. Токенизатор — `Wuglarst/src/tokenizer.py`, НЕ HuggingFace tokenizers.
4. Модель Qwen2.5-3B — обучается локально, через `train.py`/`retrain.py`.
5. Тесты: `tests/` — витая парочка; если сломал — почини и прогони `pytest`.
6. Пайтон-скрипты в корне — это одноразовые утилиты. Долгосрочные — в `scripts/`. Этот файл — инструкция такой миграции.
7. `docker-compose.yml` — источник правды для контейнеров. Если меняешь Dockerfile — обнови compose.
8. Не коммить `data/*.pkl`, `models/*`, `.env`, кэши, логи.
9. Пути в скриптах — относительные, всегда от корня, независимо от `sys.path[0]`.
10. Cc: кодовые строки — cyrillic в строках допустим, но в путях/ключах — английский.
