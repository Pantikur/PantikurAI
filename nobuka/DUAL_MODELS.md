## 🎯 Автоматический выбор модели

Нобука автоматически определяет тип задачи и выбирает модель:

### Coder модель используется когда:
- В запросе есть слова: `код`, `python`, `функция`, `класс`, `баг`, `дебаг`, `рефакт`, `паттерн`, `алгоритм`, `оптимиз`, `импорт`, `синтакс`, `async` и др.
- В запросе есть код: `def `, `class `, `import `, `from `, `return `, `yield `, `@`, `lambda `, `async def`, `await `, `try:`, `except` и др.

### General модель используется когда:
- Диалоги, эмоции, общие вопросы
- Взаимодействие с сёстрами
- Консультации по проекту
- Всё что не связано с программированием


## ⚙️ Использование в коде

### Автоматический выбор (рекомендуется):
```python
# Нобука сама выбирает модель
response = nobuka_core.generate_response("Проанализируй этот код...")
# → Использует Coder модель (задача программирования)

response = nobuka_core.generate_response("Привет, как дела?")
# → Использует General модель (диалог)
```

### Принудительное использование Coder:
```python
# Всегда использует Coder модель
response = nobuka_core.generate_coder_response("Напиши функцию для сортировки")
```

## 📝 Примечания

1. **Обе модели загружаются автоматически** при старте Нобуки
2. **Выбор модели происходит автоматически** на основе ключевых слов
3. **Если одна модель не найдена** — Нобука использует другую
4. **Coder модель быстрее** в задачах программирования (в 2-3 раза)
5. **General модель лучше** в диалогах и общих вопросах
