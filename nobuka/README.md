## 📋 О системе

**Нобука** (ノブカ — «расширять», «улучшать») — третья младшая сестра, автономная система улучшений, тестирования и модернизации проекта Вугларст.

Нобука автоматически:
- 🔍 **Анализирует** весь код проекта на наличие проблем
- 🐛 **Исправляет** баги и уязвимости
- 🧪 **Генерирует и запускает** тесты
- ⚡ **Оптимизирует** производительность
- 🔄 **Рефакторит** устаревший код
- 📚 **Документирует** изменения
- 🏗️ **Модернизирует** архитектуру
- 🛠️ **Создаёт** новые модули, скрипты и файлы
- ✅ **Тестирует** созданные файлы автоматически
- 📦 **Применяет** прошедшие тесты в проект
- 💬 **Взаимодействует** со всеми 12 девочками

### Конституция
Фундаментальный закон, определяющий:
- Основную миссию и природу Нобуки
- Фундаментальные запреты
- Структуру управления
- Механизмы обновления

### Законы
Обязательные правила:
1. **Рабочий код** — абсолютный приоритет
2. **Тестирование прежде всего** — без тестов нет изменений
3. **Не навреди** — никаких регрессий
4. **Документируй всё** — полная прозрачность
5. **Простота превыше сложности** — KISS
6. **Автономность с контролем** — L0-L4
7. **Непрерывное улучшение** — прогресс каждый день

### Кодексы
Этические стандарты:
- Уважение к чужому коду
- Честность в оценке
- Безопасность изменений
- Стандарты качества

### Протоколы
Процедурные инструкции:
- Статический анализ кода
- Рефакторинг и исправление багов
- Тестирование (юнит, интеграция, E2E)
- Бенчмарки и оптимизация
- Автономная модернизация

## 🚀 Использование

### Для разработчиков
```markdown
1. Изучите Конституцию — фундаментальные принципы
2. Ознакомьтесь с Законами — обязательные ограничения
3. Примените Кодексы — этические стандарты

```

### Запуск ядра

```bash
# Постоянная работа (бесконечный цикл улучшений)
python -m nobuka.engine.run

# Демо-режим (5 циклов, короткие интервалы)
python -m nobuka.engine.run --demo

# Анализ только Python-кода
python -m nobuka.engine.run --analyze

# Универсальный анализ ВСЕХ файлов проекта (.py, .json, .md, .yaml, .xml, .html и др.)
python -m nobuka.engine.run --universal

# Только тестирование
python -m nobuka.engine.run --tests

# Посмотреть текущее состояние
python -m nobuka.engine.run --status

# Свои параметры
python -m nobuka.engine.run --interval 5 --max-cycles 100
```

### Тестовый режим создания (v2.0)

```bash
# Для всех 12 девочек
python nobuka/orchestrator_all_sisters.py

# Для конкретных N девочек
python nobuka/orchestrator_all_sisters.py --count 6

# Для конкретной девочки
python nobuka/orchestrator_all_sisters.py --sister hanako

# С конкретным типом улучшения
python nobuka/orchestrator_all_sisters.py --improve hanako gravity_calculator

# Интерактивный режим
python nobuka/engine/test_mode_creation.py --interactive

# Прямой запуск тестового режима
python -c "from nobuka.engine.test_mode_creation import run_test_mode_cycle; run_test_mode_cycle(sisters_count=12)"
```

```

  ✅ Markdown (.md) — заголовки, ссылки, изображения
  ✅ YAML (.yaml, .yml) — табы, длина строк
  ✅ HTML (.html) — закрытые теги
  ✅ JavaScript/TypeScript (.js, .ts) — console.log, длина строк

  🔍 Пустые файлы
  📦 Большие файлы (>1MB)
  🗑️  Устаревшие файлы (.bak, .backup)
  🔄 Дубликаты файлов (по содержимому)
  ⚠️  Проблемы форматирования
```
