## 🎯 Как использовать

### Быстрый старт:
```python
from nobuka.engine.qwen_api import qwen

# Автоматический выбор
response = qwen.generate("Напиши функцию сортировки")

# Принудительный Coder
response = qwen.generate_coder("def bubble_sort(arr): pass")

# Принудительный General
response = qwen.generate_general("Привет, как дела?")
```

### Тестирование:
```bash
cd nobuka/engine
python test_qwen_minimal.py              # тест обоих моделей
python test_qwen_minimal.py --coder      # только Coder
python test_qwen_minimal.py --general    # только General
```

## 🔧 Технические детали

### Автоматический выбор модели:
- Coder ключевые слова: `код`, `python`, `функция`, `баг`, `дебаг` и др.
- General: всё остальное (диалоги, эмоции, консультации)

### Параметры генерации:
- temperature: 0.7
- top_p: 0.9
- max_new_tokens: 512 (можно изменить)

### Производительность:
- CPU: ~8 ГБ RAM на модель
- GPU (FP16): ~4 ГБ VRAM на модель
