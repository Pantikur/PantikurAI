# Расширение знаний Нобуки в программировании

## Что будет сделано

1. ✅ `programming_knowledge_base.py` — база знаний с паттернами, антипаттернами, лучшими практиками
2. ✅ `learn_programming.py` — модуль обучения из реальных источников (Python docs, StackOverflow, GitHub)
3. ✅ Обновление `web_access.py` — реальный парсинг вместо симуляции
4. ✅ Обновление `nobuka_core.py` — интеграция нового модуля в цикл обучения

## Как это работает

Нобука в своём цикле будет:
1. Искать новые знания в интернете (Python docs, StackOverflow, GitHub)
2. Сохранять их в базу знаний
3. Применять к анализу кода проекта
4. Создавать тесты для проверки новых знаний

## Запуск

```bash
python learn_programming.py --topic "asyncio"
python learn_programming.py --all
```

Или Нобука будет делать это автоматически в своём цикле улучшений.
