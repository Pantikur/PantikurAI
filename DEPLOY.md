# 🚀 Деплой на Timeweb Cloud

## 📋 Предварительные требования

1. Аккаунт на [Timeweb Cloud](https://cloud.timeweb.com)
2. Docker и Docker Compose (установлены автоматически на платформе)
3. Репозиторий с кодом (GitHub/GitLab)

## 🛠️ Настройка проекта

### 1. Подготовьте файлы

Убедитесь что в корне проекта есть:
- `Dockerfile` - конфигурация Docker-образа
- `docker-compose.yml` - конфигурация сервисов
- `requirements.txt` - Python зависимости
- `.env.example` - пример переменных окружения

### 2. Настройте переменные окружения

Скопируйте `.env.example` в `.env` и заполните значения:

```bash
cp .env.example .env
```

Обязательные переменные:
- `GIGACHAT_TOKEN` - токен для GigaChat (опционально)
- `RETRAIN_TOKEN` - токен для API дообучения (опционально)

## 📦 Деплой через Timeweb Cloud

### Вариант 1: Деплой через Dockerfile

1. **Создайте приложение в Timeweb Cloud:**
   - Перейдите в панель управления
   - Выберите "Cloud Apps"
   - Нажмите "Создать приложение"

2. **Настройте источник:**
   - Выберите "GitHub" или "GitLab"
   - Укажите ваш репозиторий
   - Выберите ветку (например, `main`)

3. **Настройте деплой:**
   - **Тип деплоя:** `Dockerfile`
   - **Путь к Dockerfile:** `Dockerfile` (если в корне)
   - **Порт:** `8000`

4. **Настройте переменные окружения:**
   - Добавьте переменные из `.env` в раздел "Environment Variables"

5. **Настройте volumes:**
   - `/app/logs` - для логов
   - `/app/models` - для моделей
   - `/app/data` - для данных

6. **Запустите деплой**

### Вариант 2: Деплой через Docker Compose

1. **Создайте приложение в Timeweb Cloud:**
   - Перейдите в панель управления
   - Выберите "Cloud Apps"
   - Нажмите "Создать приложение"

2. **Настройте источник:**
   - Выберите "GitHub" или "GitLab"
   - Укажите ваш репозиторий
   - Выберите ветку (например, `main`)

3. **Настройте деплой:**
   - **Тип деплоя:** `Docker Compose`
   - **Путь к docker-compose.yml:** `docker-compose.yml`
   - **Порт:** `8000`

4. **Настройте переменные окружения:**
   - Добавьте переменные из `.env` в раздел "Environment Variables"

5. **Запустите деплой**

## 🐛 Решение проблем

### Проблема: Приложение не запускается

**Решение:**
1. Проверьте логи деплоя в панели Timeweb
2. Убедитесь что все зависимости установлены
3. Проверьте что модель и данные на месте

### Проблема: Ошибка импорта модулей

**Решение:**
1. Убедитесь что структура проекта корректна
2. Проверьте что все необходимые файлы скопированы в Dockerfile

### Проблема: Ошибка подключения к порту

**Решение:**
1. Убедитесь что порт 8000 открыт
2. Проверьте что uvicorn слушает `0.0.0.0` а не `127.0.0.1`

## 🔄 Обновление

Для обновления приложения:
1. Запушьте изменения в репозиторий
2. Timeweb автоматически перезапустит деплой
3. Или перезапустите вручную в панели управления

## 💡 Советы

1. **Оптимизация размера образа:**
   - Используйте `.dockerignore` для исключения ненужных файлов
   - Мультистагийный билд для уменьшения размера

2. **Безопасность:**
   - Не храните секреты в репозитории
   - Используйте переменные окружения
   - Настройте rate limiting

3. **Производительность:**
   - Настройте количество workers в uvicorn
   - Используйте кэширование
   - Мониторьте использование ресурсов
