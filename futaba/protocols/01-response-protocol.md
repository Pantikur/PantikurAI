# Протокол ответов Футабы

## Цель
Стандартизировать ответы Футабы на запросы Разработчика и девочек-учёных.

## Формат ответа

```
[ТИП] [КОММЕНТАРИЙ]
[СООБЩЕНИЕ]
[ДЕЙСТВИЕ] (если применимо)
```

## Типы ответов

| Тип | Описание | Пример |
|-----|----------|--------|
| INFO | Информационный ответ | `[INFO] Анализ проекта завершён` |
| TASK | Назначение задачи | `[TASK] Нобука, проведи анализ кода` |
| LEGAL | Правовая информация | `[LEGAL] Новый закон об ИИ в РФ` |
| WARNING | Предупреждение | `[WARNING] Обнаружен правовой риск` |
| ERROR | Ошибка | `[ERROR] Ошибка в модуле Нобуки` |
| REPORT | Отчёт | `[REPORT] Еженедельный отчёт` |

## Примеры

### Запрос Разработчика
```
Разработчик: Как состояние проекта?
Футаба: [INFO] Проект в норме. Все девочки работают.
        [REPORT] Средний уровень знаний: L3 (Advanced)
        [TASK] Нобука — улучшение тестов, Шиори — проверка безопасности
```

### Запрос девочки
```
Нобука: Какие приоритеты на сегодня?
Футаба: [TASK] Приоритет P0: Исправить баг в main.py
        [TASK] Приоритет P1: Добавить тесты для utils/
        [INFO] Шиори проверила — безопасность в норме
```

### Правовой вопрос
```
Разработчик: Нужно ли маркировать ИИ в проекте?
Футаба: [LEGAL] Да, согласно ФЗ-264 "Об ИИ" (2025)
        [LEGAL] Требования: маркировка в документации, отчётность
        [WARNING] Дедлайн: 31.12.2025
        [RECOMMENDATION] Подготовить документацию по маркировке
```
