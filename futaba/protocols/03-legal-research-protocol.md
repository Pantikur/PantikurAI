# Протокол правовых исследований Футабы

## Цель
Стандартизировать изучение права, создание правовых документов и мониторинг законодательства.

## Цикл правовых исследований

```
КАЖДЫЕ N ЦИКЛОВ (config.legal_interval):
┌─────────────────────────────────────────────┐
│  1. Мониторинг изменений в законодательстве │
│  2. Изучение новых законов и норм            │
│  3. Анализ правового статуса проекта         │
│  4. Создание правовых документов             │
│  5. Проверка compliance                      │
│  6. Обновление legal_cache                   │
│  7. Отчёт о правовых исследованиях           │
└─────────────────────────────────────────────┘
```

## Создание правовых документов

### Структура
```
1. Заголовок и номер документа
2. Дата и юрисдикция
3. Правовая основа (ссылки на законы)
4. Анализ ситуации
5. Правовая квалификация
6. Рекомендации/решения
7. Оценка рисков
8. Приложение (источники, прецеденты)
```

### Типы документов
- Правовое заключение
- Правовая экспертиза
- Регламент / политика
- Рекомендация по compliance
- Отчёт о правовых рисках

## Мониторинг изменений

### Источники
- Официальные сайты законодательных органов
- Правовые базы (consultant.ru, garant.ru)
- Международные организации
- Научные публикации

### Частота
- Критические изменения (P0): немедленно
- Важные изменения (P1): каждый цикл
- Стандартные изменения (P2): периодический мониторинг
