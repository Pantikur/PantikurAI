## Ключевые возможности Футабы v3.0

### 📚 Полнота знаний о субъектах права

Футаба теперь знает ВСЕ категории:

#### Физические лица:
- ✅ Граждане РФ (полные права)
- ✅ Иностранные граждане (ограничения в политических правах)
- ✅ Апатриды (нет политических прав)
- ✅ Бипатриды (двойное гражданство)
- ✅ Возрастная дееспособность (0-14, 14-18, 18+)

#### Юридические лица:
- ✅ Коммерческие (ООО, АО, ИП)
- ✅ Некоммерческие (АНО, Фонды, Ассоциации, Учреждения)

#### Публично-правовые образования:
- ✅ Государство (РФ)
- ✅ Субъекты РФ (республики, края, области)
- ✅ Муниципальные образования

#### Социальные общности:
- ✅ Народы и нации
- ✅ Население территорий

#### Органы публичной власти:
- ✅ Министерства, службы, агентства
- ✅ Суды, прокуратура, полиция
- ✅ Налоговые инспекции

#### Общественные объединения:
- ✅ Профсоюзы
- ✅ Инициативные группы
- ✅ Религиозные группы

### 🔍 Различие контекстов

Футаба понимает разницу между:
- **Частным правом** (гражданское, семейное, трудовое) — физические и юридические лица
- **Публичным правом** (конституционное, административное, уголовное) — все категории включая публично-правовые образования

### 📊 Автоматическая генерация

- Чек-листы compliance для каждого типа субъекта
- Правовые документы с учётом категории
- Анализ правовых рисков
- Оценка применимых отраслей права

## Как использовать

### Запуск с новыми улучшениями:

```bash
# Постоянная работа
python -m futaba.engine.run

# Демо-режим (3 цикла)
python -m futaba.engine.run --demo --max-cycles 3

# Только правовые исследования
python -m futaba.engine.run --legal

# Только саморазвитие
python -m futaba.engine.run --develop

# Статус системы
python -m futaba.engine.run --status
```

### Программное использование:

```python
from futaba.engine.legal_entities import get_entities_manager, init_legal_entities

# Инициализация
manager = init_legal_entities()

# Получить всех субъектов
entities = manager.get_entity_list()

# Получить статистику
stats = manager.get_statistics()

# Получить базу знаний
knowledge = manager.get_all_knowledge()
```
