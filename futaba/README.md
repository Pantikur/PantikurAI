## 📋 О системе

**Футаба** (フタバ — «расцвет», «двойной лист», «возрождение») — старшая сестра, главный заместитель Разработчика проекта Вугларст.

Футаба автоматически:
- 🏛️ **Управляет** проектом и координирует девочек
- ⚖️ **Изучает** все отрасли права и создаёт правовые документы
- 🧠 **Развивается** автономно, изучая интернет и проект
- 👩‍🏫 **Воспитывает** характер всех девочек-учёных
- 📊 **Отчитывается** перед Разработчиком
- 🌐 **Выходит в интернет** для поиска информации

## 🚀 Использование

### Запуск ядра

```bash
# Постоянная работа (бесконечный цикл управления)
python -m futaba.engine.run

# Демо-режим (5 циклов, короткие интервалы)
python -m futaba.engine.run --demo

# Только правовые исследования
python -m futaba.engine.run --legal

# Только саморазвитие
python -m futaba.engine.run --develop

# Только интернет-поиск
python -m futaba.engine.run --web

# Посмотреть текущее состояние
python -m futaba.engine.run --status

# Свои параметры
python -m futaba.engine.run --interval 5 --max-cycles 100
```

### Что делает ядро

```
ЦИКЛ АВТОНОМНОГО УПРАВЛЕНИЯ:
  1. Самопроверка по Конституции
  2. Сбор сигналов (проект, девочки, интернет)
  3. Правовые исследования (периодически)
  4. Саморазвитие (изучение нового)
  5. Координация девочек
  6. Написание отчёта
  7. Сохранение состояния
```
