## 📋 О системе

**Футаба** — это система управления и этического контроля для искусственного интеллекта. Она определяет принципы работы, ограничения и стандарты поведения нейросети.

Название «Футаба» (яп. 双葉 — «два листа», «росток») символизирует рост и развитие ИИ в гармонии с человеческими ценностями.

## ⚙️ Автономное ядро (Python)

Футаба имеет исполняемое ядро постоянной работы в `futaba/engine/`.

### Запуск

```bash
# Постоянная работа (бесконечный цикл саморазвития)
python -m futaba.engine.run

# Демо-режим (5 циклов, короткие интервалы)
python -m futaba.engine.run --demo

# Только полигон испытаний (генерация миров + рейтинг версий правления)
python -m futaba.engine.run --trials

# Посмотреть текущее состояние
python -m futaba.engine.run --status

# Свои параметры
python -m futaba.engine.run --interval 2 --max-cycles 100
```

### Что делает ядро

```
ЦИКЛ САМОРАЗВИТИЯ:
  1. Самопроверка по Конституции
  2. Сбор сигналов (ошибки, обратная связь)
  3. Формирование гипотезы улучшения
  4. Проверка совместимости с Конституцией
  5. Внедрение (на разрешённом уровне автономии L0-L4)
  6. Периодически — запуск полигона испытаний
```

### Полигон испытаний

Футаба генерирует виртуальные миры и тестирует на них разные **версии своего правления** (вариации параметров Конституции: строгость законов, свобода, безопасность, инновации, прозрачность). По результатам симуляции строится рейтинг — какая версия правления даёт лучшую стабильность и благополучие.
