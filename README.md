# Pantikur ChatBot

Нейросетевой чат-бот с поддержкой культурных отсылок и диалектов, построенный на PyTorch + FastAPI.  
Интегрирован с Android-приложением через WebSocket и REST API.

---

## 🌟 Особенности

- LSTM-модель на PyTorch для генерации ответов
- Поддержка русских культурных отсылок и региональных фраз
- Режимы: обычный чат, генерация миров, повествование
- WebSocket-потоковый ответ (эффект "печати")
- **Автономное обучение из книг** (Project Gutenberg, Litnet, Open Library)
- **Распознавание параметров**: пол, раса, характер, темперамент
- Автообучение при добавлении новых данных
- **Защита от сканирования уязвимостей**: rate limiting, блокировка подозрительных запросов
- Деплой на Timeweb / Render / Docker
- Полная интеграция с Android (`PantikurChat`)

## ⚙️ Режимы работы бота

| Режим         | Описание |
|--------------|--------|
| `chat`       | Обычный разговор с учётом истории. Может искать значения незнакомых слов. |
| `narrative`  | Повествовательный стиль с внутренним монологом (`*(внутренне:...)*`). |
| `world_gen`  | Генерация мира: общее описание, локация, сюжетная вводная по жанру и тегу. |

### Пример запроса:
```json
{
  "messages": [
    {
      "message": "Жанр: Киберпанк, Тег: нейросети",
      "is_own": true
    }
  ],
  "mode": "world_gen"
}
```

### Формат ответа:
```
Общее описание мира:
[3-4 абзаца о мире в целом — история, атмосфера, особенности]

Локальное описание:
[конкретное место/город/локация, через которую пользователь попадает в мир]

Сюжетная вводная:
[начало истории — что происходит с пользователем прямо сейчас]
```

### По шагам:

```bash
# 1. Подготовка данных
python build_training_data.py

# 2. Обучение модели
python train.py

# 3. Генерация данных из utils (параметры, расы, характеры)
python utils/generate_params_training_data.py

# 4. Автономное обучение из книг
python utils/book_learner.py
```

### Новые данные?

```bash
# Запусти полный цикл
python retrain.py --books
```

**Бот автоматически:**
- Соберёт данные из `utils/` (параметры, расы, характеры)
- Найдёт и обработает книги по заданным темам
- Создаст обучающие пары
- Обучит модель с нуля


🛠 Поддержка знаний
knowledge_manager.py — система запоминания новых слов.
При встрече неизвестного слова — бот ищет определение.
Сохраняет в data/knowledge_cache.json.
Можно расширить обучение: python update_knowledge.py.
🔒 Безопасность
Сервер защищён от сканирования уязвимостей и DDoS:

| Защита | Описание |
|--------|----------|
| **Rate Limiting** | Макс. 30 запросов в минуту с одного IP (настраивается через `RATE_LIMIT_REQUESTS`) |
| **Блокировка IP** | Автоматическая блокировка на 24 часа при обнаружении сканирования |
| **Фильтр User-Agent** | Блокировка известных сканеров (nikto, sqlmap, nuclei и др.) |
| **Фильтр путей** | Блокировка запросов к `.env`, `.git`, `wp-admin`, `phpinfo` и т.д. |

### Мониторинг безопасности:
```bash
# Проверить статус безопасности
curl http://localhost:8000/security

# Разблокировать IP (требуется токен)
curl -X POST http://localhost:8000/security/unblock/192.168.1.100 \
  -H "X-Retrain-Token: your_token"
```

### Переменные окружения:
```bash
RATE_LIMIT_REQUESTS=30    # Запросов в минуту
BLOCK_DURATION_HOURS=24   # Длительность блокировки
```
