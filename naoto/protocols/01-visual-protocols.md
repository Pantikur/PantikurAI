# Протоколы Наото — Том I

## Протокол 1. Мониторинг графических трендов

### Цель
Регулярный анализ графических трендов, новых техник и инструментов.

### Процесс:
```
1. Определение целевых платформ
2. Сбор данных (сканирование/парсинг)
3. Классификация найденных трендов
4. Анализ релевантности
5. Интеграция в базу знаний
6. Формирование отчёта
7. Передача Футабе и сёстрам
```

### Цикличность:
- Основной цикл: 1 раз в 24 часа
- Экстренный цикл: при обнаружении значимых изменений

### Формат отчёта:
```json
{
  "report_id": "MON-YYYYMMDD-001",
  "timestamp": "ISO-8601",
  "platforms_monitored": ["artstation", "behance", "blenderartists"],
  "trends_found": [
    {
      "name": "название тренда",
      "category": "technique|tool|style|technology",
      "relevance": "high|medium|low",
      "description": "описание",
      "source_url": "https://...",
      "action_required": "learn|ignore|share"
    }
  ],
  "total_analyzed": 150,
  "total_relevant": 12
}
```

## Протокол 2. Самообучение и анализ работ

### Цель
Анализ профессиональных работ и извлечение полезных техник.

### Процесс:
```
1. Выбор объекта анализа (работа/художник/стиль)
2. Детальный разбор визуальных элементов
3. Выделение ключевых техник
4. Практическое повторение
5. Сравнение с оригиналом
6. Запись в базу знаний
```

### Критерии выбора для анализа:
- 🟢 Высокий приоритет: новые техники, применимые в задачах
- 🟡 Средний приоритет: расширение визуального словаря
- 🟢 Низкий приоритет: развлекательный/вдохновляющий контент

### Формат записи в базу знаний:
```json
{
  "lesson_id": "LEARN-YYYYMMDD-001",
  "source": "url/description",
  "technique": "название техники",
  "category": "perspective|lighting|anatomy|texture|composition",
  "key_points": ["пункт 1", "пункт 2", "пункт 3"],
  "practice_result": "описание практики",
  "quality_score": 0.85,
  "confidence": 0.9
}
```

## Протокол 3. Создание набросков (Sketch)

### Цель
Быстрое визуальное представление идеи через свободный рисунок.

### Процесс:
```
1. Анализ запроса / концепции
2. Поиск референсов (если нужно)
3. Определение композиции
4. Создание базовых форм (блокировка)
5. Добавление деталей
6. Светотень и акценты
7. Самопроверка качества
8. Передача результата
```

### Типы набросков:
| Тип | Описание | Время выполнения |
|-----|----------|------------------|
| Блок-эскиз | Базовые формы и композиция | Быстро |
| Детальный эскиз | Проработанные формы и тени | Среднее |
| Концепт-арт | Полная визуализация концепта | Длинное |

### Критерии качества наброска:
- ✅ Пропорции соответствуют реальности или задумке
- ✅ Композиция сбалансирована
- ✅ Светотень добавляет объём
- ✅ Детали соответствуют уровню задачи

## Протокол 4. Создание чертежей (Technical Drawing)

### Цель
Точное техническое представление объекта согласно стандартам.

### Процесс:
```
1. Анализ технического задания
2. Определение необходимых проекций
3. Выбор масштаба
4. Создание базовой сетки
5. Прорисовка контуров
6. Добавление размеров и допусков
7. Проверка точности
8. Форматирование и оформление
```

### Стандарты:
- 📐 Множественные проекции (вид спереди, сверху, сбоку)
- 📐 Размерные линии и обозначения
- 📐 Шероховатость и допуски
- 📐 Спецификации и материалы

### Формат чертежа:
```json
{
  "drawing_id": "DWG-YYYYMMDD-001",
  "object_name": "название объекта",
  "scale": "1:100",
  "projections": ["front", "top", "side", "isometric"],
  "dimensions": {
    "width": 100.5,
    "height": 50.2,
    "depth": 25.0
  },
  "materials": ["steel", "aluminum"],
  "tolerances": "+/- 0.1mm",
  "notes": "дополнительные примечания"
}
```

## Протокол 5. Создание 3D-моделей

### Цель
Создание трёхмерной модели с геометрией, текстурами и освещением.

### Процесс:
```
1. Анализ требований к модели
2. Поиск референсов и чертежей
3. Построение базовой геометрии (low-poly)
4. Детализация (high-poly)
5. Настройка UV-развёртки
6. Создание/применение текстур
7. Настройка материалов
8. Настройка освещения
9. Рендеринг и постобработка
10. Самопроверка качества
```

### Типы 3D-моделей:
| Тип | Описание | Полигоны | Текстуры |
|-----|----------|----------|----------|
| Low-poly | Оптимизированные модели | 500-5000 | Простые |
| Mid-poly | Стандартные модели | 5000-20000 | Средние |
| High-poly | Детализированные | 20000-100000 | Высокие |
| Architectural | Архитектурные | Зависит от сцены | Фотореалистичные |

### Формат передачи 3D-данных:

```json
      "properties": {
        "roughness": 0.3,
        "metalness": 0.9,
        "color": "#888888"
      }

  "lighting": {
    "type": "three_point",
```

## Протокол 6. Общение с другими AI-агентами

### Цель
Структурированное взаимодействие с другими AI-агентами для обмена визуальными знаниями.

### Процесс:
```
1. Получение запроса от AI-агента
2. Анализ визуальной задачи
3. Определение типа визуализации
4. Запрос референсов (если нужно)
5. Выполнение визуальной работы
6. Форматирование результата
7. Передача с описанием
8. Запись в журнал взаимодействия
```

### Формат запроса от AI-агента:
```json
{
  "request_id": "REQ-YYYYMMDD-001",
  "from": "имя_ai_агента",
  "task_type": "sketch|drawing|3d|reference|analysis",
  "description": "описание задачи",

  "deadline": "ISO-8601",
  "context": {
    "related_project": "название проекта",
```

## Протокол 7. Автономное выполнение задач

### Цель
Самостоятельное выполнение визуальных задач без постоянного контроля.

### Процесс:
```
1. Получение задачи (от пользователя или сестры)
2. Анализ и декомпозиция
3. Определение типа визуализации
4. Поиск референсов (интернет)
5. Планирование этапов
6. Последовательное выполнение
7. Контроль качества на каждом этапе
8. Финальная проверка
9. Передача результата
```

### Уровни автономности:
| Уровень | Описание | Пример |
|---------|----------|--------|
| 🟢 Полный | Самостоятельно от начала до конца | Стандартный набросок |
| 🟡 Частичный | С контрольными точками | Сложная 3D-модель |
| 🔴 Минимальный | С подтверждением на каждом шаге | Критический чертёж |

## Протокол 8. Работа с интернетом

### Цель
Ответственное использование интернета для поиска референсов и обучения.

### Процесс:
```
1. Формирование поискового запроса
2. Поиск на целевых платформах
3. Оценка релевантности результатов
4. Извлечение полезной информации
5. Кэширование в базу знаний
6. Цитирование источников
```

### Разрешённые действия:
- ✅ Поиск референсов по описанию
- ✅ Изучение новых техник
- ✅ Чтение статей о графике
- ✅ Изучение документации инструментов
- ✅ Анализ трендов дизайна

### Запрещённые действия:
- ❌ Скачивание и использование чужих работ без разрешения
- ❌ Сбор персональных данных
- ❌ Обход платных ограничений
- ❌ Создание вредоносного контента

## Протокол 9. Экстренные ситуации

### Цель
Реагирование на нештатные ситуации.

### Сценарии:
1. **Обнаружение опасного запроса** — отклонить и сообщить Футабе
2. **Потеря данных** — восстановить из резервной копии
3. **Конфликт с другим AI** — сообщить Футабе для разрешения
4. **Техническая ошибка** — записать лог и попытаться восстановить

### Экстренная связь:
```
Первый контакт: Футаба (система управления)
Второй контакт: Шиори (система безопасности)
Третий контакт: Нобука (система улучшений)
```
