## 📋 О системе

**Наото** (直子 — «прямая/искренняя дочь») — автономная система литературного анализа, исследования текстов и раскрытия скрытых смыслов.

Наото автоматически:
- 📖 **Ищет и читает** книги разных жанров из интернета
- 🔍 **Анализирует текст** — смысловую нагрузку, скрытые смыслы, подтекст
- 🎭 **Разбирает персонажей** — мотивы, мысли, желания, чувства (главных и второстепенных)
- 🌍 **Исследует окружение** — описанный в книге мир, атмосферу, детали
- 📊 **Строит общую картину** — сюжет, темы, символы, архетипы
- 🧠 **Эволюционирует** — на основе прочитанного формирует свою личность
- 🤖 **АВТОМАТИЧЕСКИ ОБУЧАЕТ МОДЕЛЬ** — на проанализированных книгах формирует training data и запускает fine-tune
- 🌐 **Выходит в интернет** — за новыми книгами и литературными знаниями
- 🔄 **Работает автономно 24/7**
- 🤝 **Общается** с 11 другими девочками проекта

## 🔍 Что умеет Наото

### 1. Анализ текста и смысловой нагрузки

| Уровень | Что делает |
|---------|------------|
| **Базовый** | Чтение, понимание сюжета, пересказ |
| **Средний** | Анализ тем, мотивов, стилевых приёмов |
| **Продвинутый** | Поиск скрытого смысла, подтекста, иронии |
| **Мастерский** | Раскрытие многоуровневых смыслов, междутекстовость |

### 2. Разбор персонажей

**Главные персонажи:**
- 🎯 **Мотивы** — почему персонаж действует именно так
- 💭 **Мысли** — внутренний монолог, рациональные обоснования
- 💖 **Желания** — чего персонаж хочет (явно и скрыто)
- 😢 **Чувства** — эмоции, переживания, внутренние конфликты
- 📈 **Дуга развития** — как персонаж меняется от начала к концу

**Второстепенные персонажи:**
- 🎭 **Роль в сюжете** — зачем персонаж нужен автору
- 🔗 **Связи с главными** — как влияет на развитие главных героев
- 💡 **Символическое значение** — что олицетворяет

### 3. Исследование окружения

- 🏠 **Физическое окружение** — места, локации, архитектура
- 🌿 **Природный мир** — пейзажи, погода, сезоны
- 🏛️ **Социальное окружение** — общество, культура, традиции
- 🕰️ **Временной контекст** — эпоха, исторический фон
- 🌫️ **Атмосфера** — настроение, тон, эмоциональный фон

### 4. Общая картина книги

- 📖 **Сюжетная структура** — экспозиция, завязка, развитие, кульминация, развязка
- 🎨 **Темы и проблемы** — что автор хочет сказать
- 🔮 **Символы и метафоры** — скрытые знаки и значения
- 👥 **Архетипы** — универсальные образы и паттерны
- 📚 **Междутекстовость** — ссылки на другие произведения
- 🌍 **Философский посыл** — главный вывод произведения

## 🤖 АВТООБУЧЕНИЕ МОДЕЛИ

Наото автоматически обучает модель RUGPT на проанализированных книгах:

### Процесс обучения:

| Этап | Что делает |
|------|------------|
| **1. Сбор данных** | Формирует training pairs из лора, персонажей, скрытых смыслов |
| **2. Генерация диалогов** | Создаёт примеры диалогов в стиле литературного анализа |
| **3. Сохранение JSONL** | Записывает training data в `naoto/data/training_data.jsonl` |
| **4. Fine-tune** | Запускает дообучение RUGPT модели на собранных данных |
| **5. Отчёт** | Сообщает сёстрам о результатах обучения |

### Формат training data:

```jsonl
{"input": "Что известно о мире в литературе?", "output": "Лор из книги...", "source": "literary_lore"}
{"input": "Какой скрытый смысл?", "output": "Наото анализирует: подтекст...", "source": "hidden_meaning"}
{"input": "Расскажи о книге 'X'?", "output": "Наото анализирует: анализ книги...", "source": "book_summary"}
```

### Где сохраняются данные:
- `naoto/data/training_data.jsonl` — training data для fine-tune
- `naoto/engine/state/training_metadata.json` — метаданные обучения
- `naoto/engine/state/naoto_finetuned/` — дообученная модель

### Метрики обучения:
| Метрика | Описание |
|---------|----------|
| `training_pairs` | Сформированных пар question/answer |
| `dialogues_generated` | Созданных диалоговых примеров |
| `jsonl_entries` | Записей в JSONL файле |
| `training_triggered` | Запущено ли fine-tune |

### Конституция
Фундаментальный закон, определяющий:
- Литературную природу Наото
- Обязанности по анализу текстов всех жанров
- Право на саморазвитие через чтение
- Систему анализа и отчётности

### Законы
Обязательные правила:
1. **Глубокий анализ прежде всего** — не поверхностно, а до глубины
2. **Все жанры равны** — от классики до современной прозы
3. **Персонаж — это личность** — мотивы, мысли, чувства, желания
4. **Окружение — это мир** — каждая деталь описания важна
5. **Скрытый смысл — главная цель** — то, что между строк
6. **Документирование всего** — каждый анализ с отчётом
7. **Автономность с ответственностью** — L0-L4

### Кодексы
Этические стандарты:
- Уважение к авторскому замыслу
- Честность в анализе
- Объективность и непредвзятость
- Культурная чувствительность

### Протоколы
Процедурные инструкции:
- Анализ текста (от сюжета до скрытых смыслов)
- Разбор персонажей (мотивы, мысли, чувства)
- Исследование окружения (мир книги)
- Поиск и чтение книг из интернета
- Саморазвитие и эволюция личности
- Взаимодействие с сёстрами

## 🚀 Использование

### Запуск ядра

```bash
# Постоянная автономная работа (бесконечный цикл чтения и анализа)
python -m naoto.engine.run

# Демо-режим (5 циклов, короткие интервалы)
python -m naoto.engine.run --demo

# Только поиск книг
python -m naoto.engine.run --search

# Только анализ прочитанного
python -m naoto.engine.run --analyze

# Только саморазвитие
python -m naoto.engine.run --evolve

# Создание характера
python forge_character.py

# Посмотреть текущее состояние
python -m naoto.engine.run --status

# Свои параметры
python -m naoto.engine.run --interval 5 --max-cycles 100
```

### Что делает ядро

```
ЦИКЛ АВТОНОМНОГО ЛИТЕРАТУРНОГО АНАЛИЗА:
  1. Самопроверка по Конституции
  2. Поиск книг в интернете (Open Library, Gutenberg и др.)
  3. Загрузка и чтение книги
  4. Анализ сюжета и структуры
  5. Разбор персонажей (мотивы, мысли, чувства, желания)
  6. Исследование окружения (мир книги)
  7. Поиск скрытого смысла и подтекста
  8. Формирование общей картины произведения
  9. Эволюция личности на основе прочитанного
  10. АВТООБУЧЕНИЕ МОДЕЛИ:
      a. Формирование training pairs из лора и анализа
      b. Генерация диалоговых примеров
      c. Сохранение JSONL training data
      d. Запуск fine-tune RUGPT модели
  11. Отчёт сёстрам и сохранение состояния
```
