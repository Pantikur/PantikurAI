# Система долгосрочного обучения чат-бота

Этот документ описывает новую систему, которая позволяет чат-боту реально учиться новым словам и сохранять знания в долгосрочной памяти модели.

## Архитектура системы

Система состоит из трех основных компонентов:

1. **KnowledgeManager** - менеджер знаний
2. **Модифицированный ChatBot** - чат-бот с интеграцией знаний
3. **Скрипты обновления** - автоматизация процесса обучения

```
project/
├── knowledge_manager.py          # Менеджер знаний
├── update_knowledge.py           # Скрипт обновления знаний
├── Wuglarst/src/chatbot.py       # Модифицированный чат-бот
└── data/knowledge/               # Данные знаний
    ├── learned_words.json        # Выученные слова и определения
    ├── training_pairs.jsonl      # Обучающие пары для дообучения
    ├── knowledge_stats.json      # Статистика знаний
    └── __pycache__/              # Кэш Python
```

## Как это работает

### 1. Накопление знаний

Когда бот встречает неизвестное слово:
1. Использует WebSearch для поиска определения
2. Сохраняет слово и его определение в `learned_words.json`
3. Обновляет статистику в `knowledge_stats.json`

### 2. Генерация обучающих данных

Система автоматически:
1. Генерирует разнообразные вопросы и ответы на основе выученных слов
2. Создает обучающие пары в формате `user: вопрос, bot: ответ`
3. Сохраняет их в `training_pairs.jsonl`

### 3. Подготовка к ретраину

Перед ретраином:
1. Объединяет пользовательские диалоги с сгенерированными обучающими парами
2. Создает единый набор данных для ретраина

### 4. Ретраин модели

Использует существующий `retrain.py` для обучения модели с нуля на объединенных данных

## Использование

### 1. Запуск чат-бота

```bash
python -m Wuglarst.src.chatbot
```

Бот автоматически:
- Накапливает знания из WebSearch
- Сохраняет их в долгосрочную память
- Периодически генерирует обучающие пары

### 2. Ручное обновление знаний

```bash
# Обновить систему знаний и подготовить данные
python update_knowledge.py
```

### 3. Ретраин модели

```bash
# После обновления знаний
python retrain.py
```

### 4. Просмотр статистики

```python
from Wuglarst.src.chatbot import ChatBot

# Инициализируем бота
bot = ChatBot("models/chat_model.pth", "data/chat_data.pkl")

# Просмотр отчета о знаниях
bot.get_knowledge_report()
```

## Функции ChatBot

Модифицированный чат-бот имеет дополнительные методы:

```python
# Получить отчет о знаниях
bot.get_knowledge_report()

# Принудительно сгенерировать обучающие пары
bot.force_generate_training_pairs(min_difficulty="medium")

# Объединить знания с диалогами
bot.merge_knowledge_with_conversations()
```

## Формат данных

### learned_words.json

```json
[
  {
    "word": "квантовый",
    "definition": "Относящийся к квантовой физике...",
    "source": "web_search",
    "added_at": "2026-05-10T10:30:00",
    "updated_at": "2026-05-10T10:30:00",
    "usage_count": 3,
    "last_used": "2026-05-10T10:30:00",
    "difficulty_level": "complex"
  }
]
```

### training_pairs.jsonl

Каждая строка - JSON объект:

```json
{"user": "что такое квантовый?", "bot": "квантовый — это Относящийся к квантовой физике...", "source": "knowledge_manager", "word": "квантовый", "difficulty": "complex", "generated_at": "2026-05-10T10:30:00"}
```

## Преимущества системы

1. **Реальное обучение** - слова и их значения сохраняются в долгосрочной памяти модели
2. **Автоматизация** - процесс накопления и ретраина автоматизирован
3. **Гибкость** - можно настраивать сложность и частоту ретраина
4. **Статистика** - ведется учет выученных слов и их использования
5. **Безопасность** - модель переобучается с нуля на всех данных

## Ограничения

1. **Размер словаря** - ограничен исходной архитектурой модели
2. **Качество определений** - зависит от источников WebSearch
3. **Ресурсы** - ретраин требует вычислительных ресурсов

## Дальнейшее развитие

1. **Адаптивный ретраин** - автоматический запуск при накоплении достаточного количества знаний
2. **Оценка качества знаний** - проверка достоверности определений
3. **Интеграция с внешними API** - использование специализированных сервисов для получения определений
4. **Многоуровневое обучение** - различные стратегии для слов разной сложности

## Автор

Эта система была разработана для реального долгосрочного обучения чат-бота на основе знаний, полученных из WebSearch.
