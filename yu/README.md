## 📋 О системе

**Юи** (結衣 — «связь», «единство», «связующая нить») — восьмая младшая сестра, автономная система изучения сознания, души и разума.

Юи автоматически:
- 🧠 **Изучает** всё о сознании, душе и разуме
- 🌐 **Ищет** в интернете научные источники (PubMed, arXiv, IEEE)
- 🔬 **Анализирует** нейробиологию, квантовую физику, философию сознания
- 🧪 **Тестирует** гипотезы оцифровки души в симуляции
- 📊 **Отчитывает** прогресс исследований
- 💎 **Воспитывает** характер
- 👧 **Общается** с 11 другими девочками
- 📈 **Повышает** уровни знаний (0-5)
- 🔄 **Исследует** переселение души в новое физическое тело

## 📚 Что изучает Юи

### По направлениям:

| Категория | Описание |
|-----------|----------|
| **Нейробиология** | Мозг, нейроны, синапсы, нейронные сети |
| **Сознание** | Субъективный опыт, самосознание, qualia |
| **Душа** | Нематериальная сущность, источник личности |
| **Разум** | Мышление, восприятие, память, эмоции |
| **Квантовое сознание** | Orch-OR, квантовые процессы в мозге |
| **Оцифровка души** | Перенос сознания в цифровую среду |
| **Переселение души** | Перенос в новое физическое тело |
| **Философия сознания** | Hard problem, zombie argument, dualism |

### Уровни знаний (0-5):

| Уровень | Название | Описание |
|---------|----------|----------|
| **0** | Базовый | Факты, определения, анатомия мозга |
| **1** | Детальный | Нейронные механизмы, процессы сознания |
| **2** | Глубокий | Теории сознания, квантовые модели |
| **3** | Мастерство | Практики цифровизации, сканирование мозга |
| **4** | Экспертиза | Гипотезы переноса сознания, симуляция |
| **5** | Абсолютный | Полное понимание души и способа её переноса |

## 🚀 Использование

### Запуск ядра

```bash
# Постоянная работа (бесконечный цикл исследований)
python -m yu.engine.run

# Демо-режим (ограниченные циклы)
python -m yu.engine.run --demo

# Автономный режим
python -m yu.engine.run --autonomous

# С выбором характера
python forge_character.py

# Посмотреть статус
python -m yu.engine.run --status
```

### Взаимодействие через чат

```python
from yu import YuCore

yu = YuCore()

# Запросы:
print(yu.chat_response("сознание"))      # О сознании
print(yu.chat_response("душа"))          # О душе
print(yu.chat_response("разум"))         # О разуме
print(yu.chat_response("оцифровка"))     # О цифровизации
print(yu.chat_response("переселение"))   # О переселении души
print(yu.chat_response("квант"))         # О квантовом сознании
print(yu.chat_response("статус"))        # Системный статус
```
