## 6. Система Случайных Встреч

Когда Филиция не целенаправленно ищет NPC, могут произойти **случайные встречи**:

### Вероятности встреч (в день)

| NPC | Вероятность | Где | Контекст |
|-----|-----------|-----|----------|
| **Ифина** | 10% | Коридоры, библиотека | Спешит, сосредоточена |
| **Элдара** | 15% | Аудитория, сад | Задумчивая, читает |
| **Серафина** | 20% | Больница, сад | Лечит, заботится |
| **Дорн** | 15% | Тренировочный зал, Бездна | Тренируется, проверяет |
| **Эрик** | 12% | Библиотека, лаборатория | С рунами, изучает |
| **Маркус** | 18% | Терраса, сад, аудитория | Шутит, рисует, общается |

### Примеры случайных встреч

> **Филиция идёт по коридору → Встречает Ифину**
> - Ифина несёт свитки, спешит
> - «Добрый день. Не мешай — Совет Магов ждёт.»
> - Или: «Подожди. У меня есть вопрос о твоей последней работе.»

> **Филиция в саду → Встречает Элару**
> - Элдара сидит на скамейке, читает
> - «А... ты. Не знала, что здесь кто-то есть.»
> - Или: «Посиди рядом. Тишина — редкость.»

> **Филиция на тренировке → Встречает Дорна**
> - Дорн проверяет студентов
> - «Ты. Подойди. Покажи, чему научилась.»
> - Или: «Неплохо. Но не достаточно.»

## 7. Цепные Реакции Взаимодействий

Действие Филиции к одному NPC влияет на других:

```
Филиция помогает Серафине → Серафина благодарна (+8)
→ Серафина лечит Филицию чаще → Дорн видит прогресс (+5)
→ Дорн доверяет больше → даёт задания на 10-й этаж
→ Элдара узнаёт → тревожится о 12-м (цель блокируется)
→ Ифина замечает → оценивает Филицию выше (+3)
→ Маркус шутит: «Ты покоряешь всех!» (+4)
```

```
Филиция нарушает запрет на 12-й этаж → Элдара расстроена (-10)
→ Элдара закрывается → Ифина подозревает тайну (-5)
→ Ифина усиливает контроль → Дорн получает больше свободы (+3)
→ Дорн тренирует Филицию жестче → Филиция становится сильнее (+7)
→ Маркус: «Дорн тебя убьёт, но ты выживешь!» (+2)
```
