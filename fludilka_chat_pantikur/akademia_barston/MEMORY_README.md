# 🧠 Система Памяти v2 — Akademia Barston

## Суть

Двухуровневая система памяти, которая **отслеживает эволюцию отношений** и **сохраняет контекст локаций**.

### Как это решает проблему из описания:

```
Этап 1: Игрок-фамильяр призван к Лилиан (слабой героине)
  → Отношения: Игрок <-> Лилиан = 20 (товарищи)

Этап 2: Виктор булит Лилиан, Игрок защищает
  → Отношения: Игрок <-> Виктор = -30 (враждебное)
  → Отношения: Игрок <-> Лилиан = 65 (близкие друзья)
  → Событие: буллинг в "Главном зале"

Этап 3: Смена локации — Игрок идёт в "Библиотеку"
  → История Главного зала сохраняется
  → Сцена начинается заново в новой локации

Этап 4: Виктор появляется в Библиотеке
  → Нейросеть получает:
    "Виктор <-> Игрок: -30 (враждебное)
     История: [protect] Игрок заступился за Лилиан"
  → Нейросеть НЕ путает локации и помнит историю
```

## Структура данных (world_memory.json)

```json
{
  "current_location": "Академия > Библиотека",
  
  "relationships": {
    "игрок||лилиан": {
      "level": 75,
      "label": "лучшие друзья",
      "history": [
        {"delta": 30, "reason": "Игрок защитил Лилиан", "event_type": "protect"},
        {"delta": 15, "reason": "Игрок рассмешил Лилиан", "event_type": "joke"}
      ]
    }
  },
  
  "locations": {
    "Академия > Главный зал": {
      "events": [
        {"type": "bullying", "description": "Виктор булит Лилиан", "participants": ["Виктор", "Лилиан"]}
      ]
    }
  },
  
  "characters": {
    "Лилиан": {"description": "...", "status": "...", "inventory": {}}
  }
}
```

## Команды

### Сцена (текущий чат)

| Команда | Описание |
|---------|----------|
| `add-chat <роль> <текст>` | Добавить сообщение в текущую сцену |
| `move <локация>` | Переместить сцену в новую локацию (старая сохраняется) |
| `current-location` | Показать текущую локацию |
| `list-chat` | Показать сообщения текущей сцены |
| `clear-scene` | Очистить текущую сцену |

### Отношения (самое важное!)

| Команда | Описание |
|---------|----------|
| `init-relationship <A> <B> [уровень]` | Инициализировать отношения (-100 до +100) |
| `update-relation <A> <B> <изменение> <причина> [тип]` | Изменить уровень отношений |
| `check-relation <A> <B>` | Показать текущий уровень и историю |
| `list-relations` | Показать все отношения |

**Уровни отношений:**
- `+80..+100` — лучшие друзья
- `+60..+79` — близкие друзья
- `+40..+59` — друзья
- `+20..+39` — товарищи
- `0..+19` — нейтральное
- `-20..-1` — охладели
- `-40..-21` — враждебное
- `-60..-41` — с враждой
- `-80..-61` — ненависть
- `-100..-81` — полная вражда

### События и локации

| Команда | Описание |
|---------|----------|
| `add-location <имя> <описание>` | Добавить локацию |
| `add-location-event <локация> <тип> <описание> [участники]` | Записать событие в локацию |
| `record-location <локация> <персонаж>` | Зафиксировать присутствие персонажа |
| `location-context <локация>` | Получить контекст локации |

### Персонажи

| Команда | Описание |
|---------|----------|
| `add-npc <имя> <описание>` | Создать/обновить персонажа |
| `set-status <имя> <статус>` | Установить статус |
| `set-position <имя> <позиция>` | Установить позицию |
| `add-item-to-inv <персонаж> <предмет> [свойства]` | Добавить предмет в инвентарь |
| `get-char <имя>` | Получить полное состояние персонажа |

### Предметы

| Команда | Описание |
|---------|----------|
| `add-item <имя> [свойства]` | Добавить предмет в мир |

### Экспорт для нейросети

| Команда | Описание |
|---------|----------|
| `get-context` | Полный контекст (всё сразу) |
| `npc-context <имя>` | Контекст конкретно для этого NPC |
| `export-context` | Экспорт в exported_context.txt |
| `summarize` | Сводка без чата |

### Сброс

| Команда | Описание |
|---------|----------|
| `clear-scene` | Очистить только текущую сцену |
| `reset-all` | Сбросить ВСЮ память (с подтверждением) |

## Как использовать с нейросетью

### Шаг 1: Добавить сообщения чата
```
add-chat player "Я иду в библиотеку"
add-chat narrator "Тёмные коридоры ведут к старому крылу"
add-chat npc Виктор "Чего тебе нужно здесь, фамильяр?"
```

### Шаг 2: Получить контекст для нейросети
```
npc-context Виктор
```

Результат:
```
=== ОТНОШЕНИЯ С ВИКТОРОМ ===
С Игрок: уровень -30 (враждебное)
  Последние события:
    [protect] Игрок публично заступился за Лилиан (-30)

=== ПРЕДЫСТОРИЯ: Виктор ===
Локация: Академия > Главный зал
  * [bullying] Виктор публично насмехается над Лилиан (с: Лилиан)

=== СОСТОЯНИЕ Виктор ===
Описание: Буллер академии, сильный маг
Позиция: Библиотека
```

### Шаг 3: Вставить в промпт
```
Ты — рассказчик в чате академии Барстон.

[ПАМЯТЬ]
<вставить вывод npc-context Виктор>
[/ПАМЯТЬ]

Текущее сообщение: Виктор спрашивает "Чего тебе нужно здесь, фамильяр?"
Ответь от лица Виктора, учитывая что он ненавидит игрока за защиту Лилиан.
```

### Шаг 4: Обновить отношения после ответа
```
# Если Виктор стал менее враждебным после разговора:
update-relation Виктор Игрок +10 "Виктор немного остыл после честного разговора" "dialogue"

# Если Лилиан и Игрок стали ближе:
update-relation Лилиан Игрок +5 "Виктор увидел, как Лилиан улыбается рядом с Игроком" "observe"
```

## Пример полного цикла

```powershell
# === НАЧАЛО ===
add-location "Академия > Главный зал" "Зал собраний"
move "Академия > Главный зал"
add-npc Лилиан "Слабая героиня"
add-npc Виктор "Буллер"
init-relationship Игрок Лилиан 20
init-relationship Игрок Виктор 0

# === БУЛЛИНГ ===
add-location-event "Академия > Главный зал" bullying "Виктор булит Лилиан" "Виктор,Лилиан"
update-relation Виктор Игрок -30 "Игрок защитил Лилиан" protect
update-relation Лилиан Игрок +30 "Игрок защитил меня" protect

# === СМЕНА ЛОКАЦИИ ===
add-location "Академия > Библиотека" "Старая библиотека"
move "Академия > Библиотека"
add-location-event "Академия > Библиотека" discovery "Нашли тайник" "Игрок,Лилиан"
update-relation Лилиан Игрок +10 "Общее приключение" "adventure"

# === ВОЗВРАТ ВИКТОРА ===
record-location "Академия > Библиотека" Виктор
npc-context Виктор        # ← контекст для нейросети
# Виктор получает ответ, отношения меняются:
update-relation Виктор Игрок +10 "Честный разговор" "dialogue"

# === ИТОГ ===
list-relations            # Проверить все отношения
```

## Технические детали

- **Файл памяти:** `world_memory.json` (единый файл)
- **Кодировка:** UTF-8 (поддержка русского)
- **Формат:** JSON (человекочитаемый, легко парсить)
- **Масштабирование:** при большом количестве сессий можно разбить на файлы
- **Скорость:** загрузка/сохранение ~1ms для типичного сценария
