# 🔄 Автономное обучение из книг (AutoBookLearning)

Модуль для **непрерывного автономного обучения** бота из книг 24/7.

## 🎯 Возможности

- ⏰ **Автоматический запуск** каждые 10 минут (настраивается)
- 📚 **Поиск книг** на Author.Today (русскоязычные бесплатные)
- 🧠 **Извлечение знаний** и создание обучающих пар
- 💾 **Накопление данных** для ретраина
- 🔄 **Циклическая работа** по всем темам
- 📊 **Сохранение состояния** (не теряет прогресс)

## 🚀 Быстрый старт

### Вариант 1: Автозапуск с ботом

Бот **сам** запускает автообучение при старте!

**Настройка в `.env`:**
```bash
# Включить автообучение (по умолчанию: true)
AUTO_BOOK_LEARNING=true

# Длительность цикла в минутах (по умолчанию: 10)
AUTO_BOOK_LEARNING_CYCLE=10

# Максимум книг за цикл (по умолчанию: 5)
AUTO_BOOK_MAX_BOOKS=5
```

**Просто запусти бота:**
```bash
python main.py
# или
uvicorn main:app --host 0.0.0.0 --port 8000
```

Бот будет:
1. ✅ Загружаться
2. 📚 Запускать автообучение в фоне
3. 🔄 Каждые 10 минут искать и читать новые книги
4. 💾 Сохранять знания в `data/books/`

### Вариант 2: Отдельный процесс

```bash
# Запуск каждые 10 минут (по умолчанию)
python utils/auto_book_learning.py

# Запуск каждые 30 минут
python utils/auto_book_learning.py --cycle 30

# Запуск каждые 15 минут, 10 книг за цикл
python utils/auto_book_learning.py --cycle 15 --books 10

# Одиночный цикл (тестирование)
python utils/auto_book_learning.py --once
```

## ⚙️ Настройки

### Командная строка

```bash
python utils/auto_book_learning.py [опции]

Опции:
  --cycle, -c       Длительность цикла в минутах (по умолчанию: 10)
  --books, -b       Максимум книг за цикл (по умолчанию: 5)
  --topics, -t      Тем за цикл (по умолчанию: 2)
  --once            Запустить один цикл и выйти
```

### Переменные окружения (.env)

```bash
# Включить/выключить автообучение
AUTO_BOOK_LEARNING=true

# Длительность цикла (минуты)
AUTO_BOOK_LEARNING_CYCLE=10

# Максимум книг за цикл
AUTO_BOOK_MAX_BOOKS=5

# Тем за цикл
AUTO_BOOK_TOPICS=2
```

## 📊 Как это работает

### Цикл обучения (10 минут):

```
1. [00:00] Запуск цикла
   ├─ Выбор тем: "фэнтези", "попаданцы"
   ├─ Поиск книг на Author.Today (бесплатные)
   ├─ Скачивание 5 книг (описания/аннотации)
   ├─ Обработка и очистка
   ├─ Генерация ~15 обучающих пар
   └─ Сохранение в data/books/books_cycle_20260623_120000.jsonl

2. [10:00] Следующий цикл
   ├─ Новые темы: "фантастика", "мистика"
   └─ ...

3. [20:00] Третий цикл
   ├─ Темы: "детектив", "приключения"
   └─ ...

4. [23:50] Последний цикл дня
   └─ Итого: ~144 цикла × 15 пар = 2160 новых пар/день
```

### Темы (циклически):

**Всего 20+ тем**, обрабатываются по 2 за цикл:

1. фэнтези
2. попаданцы
3. фантастика
4. мистика
5. детектив
6. приключения
7. психология общения
8. философия жизни
9. эмоциональный интеллект
10. самопознание
11. психология отношений
12. современная проза
13. боевое фэнтези
14. городское фэнтези
15. научная фантастика
16. альтернативная история
17. литРПГ
18. ужасы
19. романтика
20. драма

**Полный цикл:** ~100 минут (20 тем ÷ 2 за цикл × 10 минут)

## ⚠️ Ограничения

1. **API лимиты**: Project Gutenberg может ограничивать запросы
2. **Авторские права**: Только книги из общественного достояния
3. **Качество**: Может требоваться фильтрация
4. **Трафик**: ~1-5 МБ за цикл (зависит от книг)

## ⚠️ Ограничения

1. **Author.Today**: Только книги с бесплатным доступом
2. **Описания книг**: ~300-1000 символов (аннотации, не полные тексты)
3. **Русскоязычные**: Только русские книги (Author.Today)
4. **Трафик**: ~1-3 МБ за цикл (зависит от книг)

## 📈 Статистика обучения

**При цикле 10 минут:**
- Циклов в день: **144** (24 часа × 6 циклов/час)
- Книг в день: **~720** (5 книг × 144 цикла)
- Пар в день: **~2160** (15 пар × 144 цикла)
- Тем в день: **~288** (2 темы × 144 цикла, с повторами)

**При цикле 30 минут:**
- Циклов в день: **48**
- Книг в день: **~240**
- Пар в день: **~720**

**При цикле 1 час:**
- Циклов в день: **24**
- Книг в день: **~120**
- Пар в день: **~360**

## 🔧 Диагностика

### Автообучение не запускается

Проверьте `.env`:
```bash
AUTO_BOOK_LEARNING=true  # должно быть true
```

### Ошибки в логах

Смотрите лог:
```bash
cat data/books/auto_learning.log
```

### Книги не находятся

- Проверьте интернет-соединение
- Author.Today может быть недоступен временно
- Увеличьте `max_books_per_cycle`

### Мало пар

- Уменьшите `min_text_length` в `utils/book_learner.py`
- Увеличьте `max_chunks_per_book`
- Добавьте больше тем
