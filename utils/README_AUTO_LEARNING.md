# 🔄 Автономное обучение из книг (AutoBookLearning)

Модуль для **непрерывного автономного обучения** бота из книг 24/7.

## 🎯 Возможности

- ⏰ **Автоматический запуск** каждый час (настраивается)
- 📚 **Поиск книг** в Project Gutenberg
- 🧠 **Извлечение знаний** и создание обучающих пар
- 💾 **Накопление данных** для ретраина
- 🔄 **Циклическая работа** по всем темам
- 📊 **Сохранение состояния** (не теряет прогресс)

## 🚀 Быстрый старт

### Вариант 1: Автозапуск с ботом

Бот **сам** запускает автообучение при старте!

**Настройка в `.env`:**
```bash
# Включить автообучение (по умолчанию: true)
AUTO_BOOK_LEARNING=true

# Интервал в часах (по умолчанию: 1)
AUTO_BOOK_LEARNING_INTERVAL=1
```

**Просто запусти бота:**
```bash
python main.py
# или
uvicorn main:app --host 0.0.0.0 --port 8000
```

Бот будет:
1. ✅ Загружаться
2. 📚 Запускать автообучение в фоне
3. 🔄 Каждые 1 час искать и читать новые книги
4. 💾 Сохранять знания в `data/books/`

### Вариант 2: Отдельный процесс

```bash
# Запуск каждые 1 час (по умолчанию)
python utils/auto_book_learning.py

# Запуск каждые 3 часа
python utils/auto_book_learning.py --interval 3

# Запуск каждые 6 часов, 5 книг за цикл
python utils/auto_book_learning.py --interval 6 --books 5

# Одиночный цикл (тестирование)
python utils/auto_book_learning.py --once
```

## ⚙️ Настройки

### Командная строка

```bash
python utils/auto_book_learning.py [опции]

Опции:
  --interval, -i    Интервал в часах (по умолчанию: 1)
  --books, -b       Максимум книг за цикл (по умолчанию: 3)
  --topics, -t      Тем за цикл (по умолчанию: 2)
  --once            Запустить один цикл и выйти
```

### Переменные окружения (.env)

```bash
# Включить/выключить автообучение
AUTO_BOOK_LEARNING=true

# Интервал между циклами (часы)
AUTO_BOOK_LEARNING_INTERVAL=1

# Максимум книг за цикл
AUTO_BOOK_MAX_BOOKS=3

# Тем за цикл
AUTO_BOOK_TOPICS=2
```

## 📊 Как это работает

### Цикл обучения:

```
1. [00:00] Запуск цикла
   ├─ Выбор тем: "психология общения", "философия жизни"
   ├─ Поиск книг в Gutenberg
   ├─ Скачивание 3 книг
   ├─ Обработка и очистка
   ├─ Генерация ~20 обучающих пар
   └─ Сохранение в data/books/books_cycle_20260623_120000.jsonl

2. [01:00] Следующий цикл
   ├─ Новые темы: "фэнтези миры", "научная фантастика"
   └─ ...

3. [02:00] Третий цикл
   ├─ Темы: "эмоциональный интеллект", "самопознание"
   └─ ...

4. [23:00] Последний цикл дня
   └─ Итого: ~24 цикла × 20 пар = 480 новых пар/день
```

### Темы (циклически):

**Всего 20+ тем**, обрабатываются по 2 за цикл:

1. психология общения
2. философия жизни
3. эмоциональный интеллект
4. самопознание
5. психология отношений
6. экзистенциальная психология
7. фэнтези миры
8. магические системы
9. эльфы и гномы
10. драконы и демоны
11. научная фантастика
12. космос и цивилизации
13. искусственный интеллект
14. классическая литература
15. современная проза
16. приключенческие романы
17. мотивация и успех
18. тайм-менеджмент
19. лидерство
20. креативность

**Полный цикл:** ~10 часов (20 тем ÷ 2 за цикл × 1 час)

## ⚠️ Ограничения

1. **API лимиты**: Project Gutenberg может ограничивать запросы
2. **Авторские права**: Только книги из общественного достояния
3. **Качество**: Может требоваться фильтрация
4. **Трафик**: ~1-5 МБ за цикл (зависит от книг)

## 📈 Статистика обучения

**При интервале 1 час:**
- Циклов в день: **24**
- Книг в день: **~72** (3 книги × 24 цикла)
- Пар в день: **~480** (20 пар × 24 цикла)
- Тем в день: **~48** (2 темы × 24 цикла, с повторами)

**При интервале 6 часов:**
- Циклов в день: **4**
- Книг в день: **~12**
- Пар в день: **~80**

## 🔧 Диагностика

### Автообучение не запускается

Проверьте `.env`:
```bash
AUTO_BOOK_LEARNING=true  # должно быть true
```

### Ошибки в логах

Смотрите лог:
```bash
cat data/books/auto_learning.log
```

### Книги не находятся

- Проверьте интернет-соединение
- Gutenberg может быть недоступен временно
- Увеличьте `max_books_per_cycle`

### Мало пар

- Уменьшите `min_text_length` в `book_learner.py`
- Увеличьте `max_chunks_per_book`
- Добавьте больше тем
