# 🧠 Обучение на параметрах человека и расах

Этот модуль автоматически генерирует обучающие данные из файлов:
- `utils/human_params.py` — параметры человека (пол, цвет кожи, волос, телосложение, анатомия)
- `utils/races.py` — расы персонажей (эльфы, гномы, орки, демоны и др.)

## 📊 Что включается в обучение

### Параметры человека
- **Пол**: мальчик, девочка, футанари
- **Цвет кожи**: светлая, смуглая, темная
- **Цвет волос**: блондин, рыжая, каштановая, чёрная, натуральная, розовый, голубой, фиолетовый, зеленый, пепельный, радужный
- **Телосложение**: стройное, спортивное, мускулистое, пышное, среднее
- **Размер груди**: маленькая, средняя, большая, огромная
- **Мужская анатомия**: размер, толщина, форма
- **Женская анатомия**: форма, выделения

### Расы персонажей
- **Основные расы**: человек, эльф, гном, орк, хоббит, тролль, огр, великан, драконид, тифлинг, фея, нежить, кентавр, гоблин, кобольд, ящер, табакси, аараконра, генаси, аасимар, голем, пикси, сатир, мерфолк, кенку, фирболг, голиаф, багбир, кимономи, флюгели, демон
- **Подкатегории**: высший эльф, тёмный эльф, лесной эльф, горный гном, холмовой гном, различные типы демонов и др.

## 🚀 Как использовать

### Вариант 1: Автоматически через `retrain.py`

```bash
python retrain.py
```

Скрипт автоматически:
1. Сгенерирует данные из `utils/human_params.py` и `utils/races.py`
2. Соберёт все остальные данные (диалоги, знания)
3. Запустит ретраин модели

### Вариант 2: Ручная генерация данных

```bash
# 1. Генерация данных из utils
python utils/generate_params_training_data.py

# 2. Запуск ретраина
python retrain.py
```

### Вариант 3: Через `build_training_data.py`

```bash
python build_training_data.py
python train.py
```

## 📁 Структура данных

Данные сохраняются в:
- `data/params_training_pairs.jsonl` — сгенерированные пары из utils
- `data/training_pairs.jsonl` — все обучающие пары (включая params)
- `data/conversations.json` — диалоговые сессии

## ⚙️ Настройка

### Изменение количества примеров

В файле `utils/generate_params_training_data.py` измените:

```python
COUNT_PER_CATEGORY = 3  # Количество примеров на каждую категорию
```

Больше примеров → лучше обучение, но дольше тренировка.

### Добавление новых шаблонов

Добавьте шаблоны в словари:

```python
HUMAN_PARAMS_TEMPLATES = {
    "gender": [
        "Я {value}, хочу пообщаться.",
        "Привет, я {value}.",
        # Добавьте свои шаблоны
    ],
    # ...
}
```

### Добавление новых категорий

1. Добавьте ключевые слова в `utils/human_params.py` или `utils/races.py`
2. Добавьте обработку в `utils/generate_params_training_data.py`

## 🔍 Диагностика

### Данные не генерируются

Проверьте, что файлы существуют:
```bash
ls utils/human_params.py
ls utils/races.py
```

### Ошибки импорта

Убедитесь, что зависимости установлены:
```bash
pip install pydantic
```

### Модель не распознаёт параметры

Увеличьте количество примеров:
```python
COUNT_PER_CATEGORY = 5  # или больше
```
