# 📚 BookLearner — Автономное обучение из книг

Модуль для автоматического поиска, скачивания и обработки книг для обучения модели.

## 🚀 Возможности

- **Поиск книг** через Project Gutenberg и Google Books API
- **Автоматическая загрузка** текстов в формате UTF-8
- **Обработка и очистка** от служебных блоков
- **Генерация обучающих пар** из текстов книг
- **Кэширование** обработанных книг (не обрабатывает дважды)
- **Тематический поиск** по заданным темам

## 📖 Как использовать

### Быстрый старт

```bash
# Запуск автономного обучения
python utils/book_learner.py
```

### Через Python API

```python
from utils.book_learner import BookLearner

learner = BookLearner()

# Обучение по конкретным темам
topics = ["психология", "философия", "фэнтези"]
pairs = learner.learn_from_books(topics=topics, max_books=10)

# Сохранение
learner.save_training_pairs(pairs, "data/books_training_pairs.jsonl")

# Статистика
stats = learner.get_statistics()
print(f"Обработано книг: {stats['total_books']}")
```

### Интеграция с ретраином

```bash
# 1. Сбор знаний из книг
python utils/book_learner.py

# 2. Запуск ретраина
python retrain.py
```

## ⚙️ Настройки

В классе `BookLearner` можно настроить:

```python
learner = BookLearner(
    data_dir="data/books",        # Директория для книг
    cache_dir="data/cache",       # Кэш
)

# Параметры обработки
learner.max_books_per_topic = 2   # Книг на тему
learner.min_text_length = 1000    # Мин. длина текста
learner.chunk_size = 500          # Размер чанка
learner.max_chunks_per_book = 20  # Макс. чанков на книгу
```

- ✅ Много классики

## ⚠️ Ограничения

1. **Авторские права**: Используйте только книги из общественного достояния
2. **API лимиты**: Gutenberg и Google Books имеют ограничения на запросы
3. **Качество текста**: Может требоваться дополнительная очистка
4. **Язык**: Лучше работает с русскоязычными книгами

## 🔧 Диагностика

### Книги не находятся
- Проверьте интернет-соединение
- Попробуйте другие темы
- Увеличьте `max_books_per_topic`

### Ошибки скачивания
- Проверьте доступность Gutenberg
- Увеличьте таймаут в `download_gutenberg_text()`

### Мало обучающих пар
- Уменьшите `min_text_length`
- Увеличьте `max_chunks_per_book`
- Добавьте больше тем
