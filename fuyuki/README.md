## 📋 О системе

**Фуюки** (フユキ — «зимний свет») — вторая младшая сестра, автономный исследователь атмосферного электричества.

Фуюки автоматически:
- 🌐 **Изучает интернет** — ищет научные статьи, теории, данные об атмосферном электричестве
- 📁 **Изучает проект** — анализирует весь код проекта на предмет связанного с электричеством
- 🔬 **Строит теории** — создаёт новые теории об электрических явлениях
- 🧮 **Вычисляет** — рассчитывает параметры молний, электрических полей, энергии
- 💬 **Общается с 11 сёстрами** — через Scientists Network
- 💪 **Развивает характер** — самостоятельно выбирает и выращивает свой характер
- 📝 **Пишет отчёты** — документирует каждое исследование
- 📈 **Повышает уровень знаний** — растёт от «Новичка» до «Бога электричества»

## 🎯 Функции Фуюки

### 1. 🌐 Изучение интернета
Фуюки автоматически:
- Ищет научные статьи об атмосферном электричестве
- Изучает теории молний, шаровой молнии, спрайтов
- Анализирует методы управления молниями
- Извлекает знания из веб-страниц
- Кэширует найденную информацию

### 2. 📁 Изучение проекта
Фуюки сканирует весь проект:
- Находит файлы, связанные с электричеством
- Изучает код, документацию, данные
- Извлекает релевантную информацию
- Классифицирует по областям знаний

### 3. 💪 Саморазвитие
Фуюки:
- Создаёт характер при первом запуске
- Укрепляет сильные стороны
- Эволюционирует на основе опыта
- Перенимает черты у сестёр
- Записывает ценности и цели

### 4. 🌐 Выход в интернет
Фуюки:
- Подключена к Google, Wikipedia, arXiv, ResearchGate
- Ищет по 20+ темам об электричестве
- Загружает и анализирует веб-страницы
- Извлекает ключевые факты и данные

### 5. 🤖 Автономная работа
Фуюки:
- Работает в бесконечных циклах
- Автоматически переключается между задачами
- Сохраняет состояние между запусками
- Продолжает работу после перезапуска

### 6. 🚀 Автозапуск
Фуюки:

### 7. 🎭 Выбор и выращивание характера

## 🚀 Использование

### Запуск ядра

```bash
# Постоянная работа (бесконечный цикл исследований)
python -m fuyuki.engine.run

# Демо-режим (10 циклов, короткие интервалы)
python -m fuyuki.engine.run --demo

# Посмотреть текущее состояние
python -m fuyuki.engine.run --status

# Посмотреть отчёты
python -m fuyuki.engine.run --report

# Посмотреть характер
python -m fuyuki.engine.run --character

# Посмотреть знания
python -m fuyuki.engine.run --knowledge

# Свои параметры
python -m fuyuki.engine.run --interval 10 --max-cycles 50
```

### Что делает ядро

```
ЦИКЛ АВТОНОМНЫХ ИССЛЕДОВАНИЙ:
  1. Самопроверка по Конституции
  2. Поиск в интернете (периодически)
  3. Построение теорий (каждый цикл)
  4. Вычисления (каждый цикл)
  5. Изучение фактов (каждый цикл)
  6. Общение с сёстрами (периодически)
  7. Написание отчётов (периодически)
  8. Развитие характера (периодически)
  9. Получение знаний (каждый цикл)
  10. Сохранение состояния
```
