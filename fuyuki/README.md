# ⚡ Фуюки — Исследователь атмосферного электричества

## Описание

**Фуюки** (冬木 — "зимнее дерево") — девочка-учёный, специализирующаяся на изучении атмосферного электричества.

### Миссия
Изучить атмосферное электричество, построить теории, вычислить возможности и найти способ обуздать атмосферное электричество.

### Направления исследований
- 📚 Изучение атмосферного электричества в интернете
- 🔬 Построение физических теорий
- 🧮 Вычисление электрических параметров
- 🌩️ Поиск способов управления молниями
- 📊 Анализ экспериментальных данных
- ⚡ Применение электрических технологий

## Запуск

```bash
# Постоянная работа
python -m fuyuki.engine.run

# Демо-режим
python -m fuyuki.engine.run --demo

# Только изучение в интернете
python -m fuyuki.engine.run --research

# Только построение теорий
python -m fuyuki.engine.run --theories

# Только вычисления
python -m fuyuki.engine.run --calc

# Статус
python -m fuyuki.engine.run --status
```

## Компоненты

### 1. Исследователь электричества
- Сканирует интернет на предмет исследований атмосферного электричества
- Анализирует научные статьи о молниях
- Изучает эксперименты

### 2. Построитель теорий
- Создаёт теории атмосферного электричества
- Проверяет совместимость с физикой
- Оценивает научную ценность

### 3. Вычислитель
- Проводит расчёты электрических параметров
- Моделирует разряды молний
- Оптимизирует параметры захвата

### 4. Интернет-доступ
- Поиск научных статей
- Мониторинг новых открытий
- Анализ данных о молниях
