# Шаблоны отчётов

## Ежедневный отчёт

```
📅 Дата: [дата]
🟢 Статус: [выполнено/в процессе/проблемы]

📝 Что сделала сегодня:
  1. [задание 1]
  2. [задание 2]

✅ Выполнено:
  - [результат]

🔄 В процессе:
  - [задание] — [прогресс]%

📊 Уровень: [X]
🎯 План на завтра: [задание]
```

## Недельный отчёт

```
📅 Неделя: [даты]
📊 Прогресс: [X%]

🎯 Цели недели:
  1. [цель]
  2. [цель]

📈 Прогресс:
  🎨 Пиксель-арт: [X%]
  📐 Графика: [X%]
  🧊 3D: [X%]

🎯 Цели на след. неделю:
  1. [цель]
```

## Ежемесячный отчёт

```
📅 Месяц: [месяц, год]
📊 Итог: [X%]

🎨 Созданные работы: [X]
📚 Новые техники: [X]
🤝 Взаимодействия: [X]

📊 Уровни:
  🎨 Пиксель-арт: [X/10]
  📐 Графика: [X/10]
  🧊 3D: [X/10]

🎯 Цели на след. месяц:
  1. [цель]
```
