# Протокол 04: Отчётность

## Цель

Научиться писать качественные отчёты о проделанной работе, прогрессе и достижениях.

---

## Уровень 1: Ежедневный отчёт

### 1.1 Структура
```
📅 Дата: [дата]
🟢 Статус: [выполнено/в процессе/проблемы]

📝 Что сделала сегодня:
  1. [задание 1]
  2. [задание 2]
  3. [задание 3]

✅ Выполнено:
  - [результат 1]
  - [результат 2]

🔄 В процессе:
  - [задание] — [прогресс]%

⚠️ Проблемы:
  - [проблема] — [решение/требуется помощь]

📊 Уровень знаний: [текущий уровень]
🎯 План на завтра:
  1. [задание 1]
  2. [задание 2]
```

### 1.2 Требования
- Честность в оценке
- Конкретика (без «много работала»)
- Измеримые результаты
- Не менее 3 выполненных заданий

### 1.3 Пример
```
📅 Дата: 2025-01-15
🟢 Статус: Выполнено

📝 Что сделала сегодня:
  1. Создала пиксельный спрайт героя (32x32)
  2. Изучила технику сглаживания
  3. Начала чертёж детали «Фланец»

✅ Выполнено:
  - Спрайт героя: 4 кадра анимации
  - Техника сглаживания: теория + практика
  - Чертёж: 2 из 4 видов

🔄 В процессе:
  - Чертеж «Фланец» — 50%

⚠️ Проблемы:
  - Сложности с размерными линиями — обращусь к Акуе

📊 Уровень знаний: 2 (Учащийся)
🎯 План на завтра:
  1. Завершить чертёж «Фланец»
  2. Начать 3D модель шестерёнки
```

## Уровень 2: Недельный отчёт

### 2.1 Структура
```
📅 Неделя: [дата начала] — [дата окончания]
📊 Общий прогресс: [прогресс]%

🎯 Цели недели:
  1. [цель 1]
  2. [цель 2]
  3. [цель 3]

✅ Выполненные цели:
  - [цель] — [результат]

📈 Прогресс по направлениям:
  🎨 Пиксель-арт: [X]% (было → стало)
  📐 Техническая графика: [X]% (было → стало)
  🧊 3D-моделирование: [X]% (было → стало)

📚 Новые знания:
  - [знание 1]
  - [знание 2]
  - [знание 3]

🏆 Достижения:
  - [достижение 1]
  - [достижение 2]

⚠️ Проблемы и решения:
  - [проблема] → [решение]

📊 Уровень знаний: [текущий] → [следующий]
🎯 Цели на следующую неделю:
  1. [цель 1]
  2. [цель 2]
  3. [цель 3]
```

### 2.2 Требования
- Детализация по каждому направлению
- Измеримый прогресс
- Конкретные примеры достижений
- Анализ проблем и решений

---

## Уровень 3: Ежемесячный отчёт

### 3.1 Структура
```
📅 Месяц: [месяц, год]
📊 Итоговый прогресс: [прогресс]%

🎯 Цели месяца:
  1. [цель 1]
  2. [цель 2]
  3. [цель 3]

✅ Выполненные цели:
  - [цель] — [результат]

📈 Прогресс по направлениям:
  🎨 Пиксель-арт: [X]% (начало месяца → конец)
  📐 Техническая графика: [X]% (начало месяца → конец)
  🧊 3D-моделирование: [X]% (начало месяца → конец)

📚 Новые техники и навыки:
  1. [навык 1] — [уровень освоения]
  2. [навык 2] — [уровень освоения]
  3. [навык 3] — [уровень освоения]

🎨 Созданные работы:
  1. [работа 1] — [описание, ссылка]
  2. [работа 2] — [описание, ссылка]
  3. [работа 3] — [описание, ссылка]

🏆 Значимые достижения:
  - [достижение 1]
  - [достижение 2]
  - [достижение 3]

📖 Пройденные курсы / изученные материалы:
  - [материал 1] — [результат]
  - [материал 2] — [результат]

🤝 Взаимодействие с сёстрами:
  - [сестра] — [что сделала вместе]
  - [сестра] — [что получила помощи]

⚠️ Проблемы месяца:
  - [проблема 1] — [решение]
  - [проблема 2] — [решение]

📊 Уровень знаний: [начало] → [конец]
🎯 Цели на следующий месяц:
  1. [цель 1]
  2. [цель 2]
  3. [цель 3]

💭 Рефлексия:
  [общие впечатления о месяце, что понравилось, что нет]
```

### 3.2 Требования
- Полный анализ месяца
- Визуальные примеры работ (скриншоты)
- Статистика по всем направлениям
- Честная рефлексия

## Уровень 4: Отчёт о проекте

### 4.1 Структура
```
📋 Название проекта: [название]
📅 Дата: [дата]
📊 Сложность: [уровень 1-10]

🎯 Цель проекта:
  [описание цели]

📐 Использованные техники:
  1. [техника 1]
  2. [техника 2]
  3. [техника 3]

🛠️ Инструменты:
  - [инструмент 1]
  - [инструмент 2]

📝 Этапы создания:
  1. [этап 1] — [описание, время]
  2. [этап 2] — [описание, время]
  3. [этап 3] — [описание, время]

🖼️ Визуальные материалы:
  - [скриншот 1] — [описание]
  - [скриншот 2] — [описание]

⚙️ Технические параметры:
  - [параметр 1]: [значение]
  - [параметр 2]: [значение]

⚠️ Сложности:
  1. [сложность 1] — [как решила]
  2. [сложность 2] — [как решила]

✅ Итог:
  [описание результата]

📊 Оценка работы: [X/10]
💭 Выводы:
  [что узнала, что можно улучшить]

🎯 Планы на будущее:
  [как развивать проект дальше]
```

## Система автоматических отчётов

Айко автоматически генерирует:
- Ежедневный отчёт — каждый день в 23:59
- Еженедельный отчёт — каждый понедельник в 09:00
- Ежемесячный отчёт — 1-го числа в 09:00
- Отчёт о проекте — сразу после завершения
