## Раздел 1. Протокол чтения книги

### 1.1 Подготовительный этап
```
ПЕРЕД ЧТЕНИЕМ:
┌─────────────────────────────────────────────┐
│  CHECKLIST ПОДГОТОВКИ К ЧТЕНИЮ             │
├─────────────────────────────────────────────┤
│  □ Определить тип книги (художественная,   │
│    научная, техническая)                   │

│  □ Определить цели чтения                  │
│  □ Подготовить структуру извлечения        │
└─────────────────────────────────────────────┘
```

### 1.2 Процесс чтения
```
ЭТАПЫ ЧТЕНИЯ:
  1. 📖 Введение — понять контекст
  2. 📚 Основная часть — извлечь знания
  3. 🔍 Анализ — разобрать лор/факты
  4. 💡 Выводы — сформулировать мысли
  5. 📝 Сохранение — создать обучающие пары
```

## Раздел 2. Протокол извлечения знаний

### 2.1 Категории знаний
| Категория | Описание | Пример |
|-----------|----------|--------|
| **Факты** | Утверждения, которые можно проверить | "Вода кипит при 100°C" |
| **Концепции** | Идеи и теории | "Теория относительности" |
| **Сюжеты** | Художественные сюжеты | "Герой проходит путь" |
| **Персонажи** | Характеристики персонажей | "Иван — отважный воин" |
| **Стили** | Литературные приёмы | "Использование метафор" |

### 2.2 Формат сохранения
```python
knowledge_pair = {
    "source": "book_title",
    "chapter": 5,
    "page": 123,
    "category": "fact|concept|plot|character|style",
    "question": "Вопрос для обучения",
    "answer": "Ответ из книги",
    "context": "Контекст для понимания",
    "tags": ["тег1", "тег2"],
    "confidence": 0.95,
}
```

### 3.2 Выявление противоречий
```python
def check_consistency(lore_entries):
    for entry in lore_entries:
        if entry.has_contradiction():
            mark_as_conflict(entry)
```

## Раздел 4. Протокол обучения модели

### 4.1 Создание обучающих пар
```
ПРОЦЕСС СОЗДАНИЯ ПАР:
  1. Извлечь ключевую идею
  2. Сформулировать вопрос
  3. Найти ответ в тексте
  4. Добавить контекст
  5. Проверить валидность
```

```json

    "messages": [

        "category": "knowledge"
```
