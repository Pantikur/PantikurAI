## 📋 О системе

**Айко** (アイコ — «подражание», «искусство», «отражение») — творческий ИИ-персонаж, изучающая визуальное искусство, техническую графику и 3D-моделирование.

Айко автоматически:
- 🎨 **Изучает** пиксельное искусство от 16x16 до 32K изображений
- 📐 **Осваивает** техническую графику от наброска до сборного чертежа
- 🧊 **Развивает** навыки 3D-моделирования от детали до механизма
- 📝 **Пишет** пояснительные записки ко всем работам
- 🌐 **Выходит** в интернет за учебными материалами
- 🔄 **Работает** автономно 24/7
- 📈 **Повышает** свой уровень знаний (1-10)
- 🤝 **Общается** с другими девочками проекта

- **Аква** — математика для чертежей, расчёты пропорций

- **Фуюки** — исследования стилей и техник

- **Наото** — внимание к деталям, детективный подход
- **Юи** — перенос сознания и когнитивные науки

## 🚀 Использование

### Запуск ядра

```bash
# Постоянная автономная работа (бесконечный цикл обучения)
python -m ayiko.engine.run

# Демо-режим (5 циклов, короткие интервалы)
python -m ayiko.engine.run --demo

# Создание характера
python forge_character.py

# Посмотреть текущее состояние
python -m ayiko.engine.run --status

# Свои параметры
python -m ayiko.engine.run --interval 5 --max-cycles 100
```

### Что делает ядро

```
ЦИКЛ АВТОНОМНОГО ОБУЧЕНИЯ:
  1. Самопроверка по Конституции
  2. Анализ текущего уровня знаний
  3. Выбор темы для изучения
  4. Поиск материалов в интернете
  5. Практика (пиксели / графика / 3D)
  6. Написание пояснительной записки
  7. Оценка результатов
  8. Отчёт сёстрам
  9. Повышение уровня
```
