## 📋 О системе

**Айко** (愛子 — «любимая дочь») — двенадцатая младшая сестра, автономная система чтения книг и обучения модели на основе литературных источников.

Айко автоматически:
- 📖 **Читает** книги из директории проекта
- 🧠 **Извлекает** знания (факты, концепции, сюжеты)
- ✍️ **Анализирует** стиль повествования
- 🌍 **Разбирает** лор (для художественных книг)
- 💡 **Создаёт** обучающие пары
- 🚀 **Обучает** модель на основе прочитанного

## 🚀 Использование

### Запуск ядра

```bash
# Постоянная работа (бесконечный цикл чтения)
python -m ayiko.engine.run

# Демо-режим (5 циклов, короткие интервалы)
python -m ayiko.engine.run --demo

# Свои параметры
python -m ayiko.engine.run --interval 5 --max-cycles 100
```

### Добавление книг

Положите книги в папку `data/books/`:
```
data/books/
├── book1.txt
├── book2.epub
├── book3.md
└── book4.json
```

### Что делает ядро

```
ЦИКЛ АВТОНОМНОГО ЧТЕНИЯ:
  1. 📖 Чтение книги из директории
  2. 🧠 Извлечение знаний (факты, концепции, сюжеты)
  3. ✍️ Анализ стиля повествования
  4. 🌍 Разбор лора (персонажи, мир, хронология)
  5. 💡 Создание обучающих пар
  6. 🚀 Обучение модели
  7. 💾 Сохранение состояния
  8. 📊 Отчёт о проделанной работе
```
