## 🤖 Функции

### 1. Саморазвитие
```bash
curl -X POST http://localhost:8000/latislane/self-improve
```
- Анализ пробелов в знаниях
- Обновление низкой уверенности
- Укрепление характера
- Социальное развитие
- Написание отчётов

### 2. Выход в интернет
- Реальный веб-поиск через WebResearcher
- PubMed API (медицина)
- Wikipedia API (наука)
- arXiv API (научные статьи)
- GitHub (код проекта)

### 3. Автономная работа
```bash
curl -X POST http://localhost:8000/latislane/autonomous \
  -H "Content-Type: application/json" \
  -d '{"interval_minutes": 10}'
```

Автостоп:
```bash
curl -X POST http://localhost:8000/latislane/autonomous/stop
```

Автономный цикл:
1. Изучение тем из интернета
2. Социальные взаимодействия
3. Укрепление характера
4. Написание отчётов
5. Сохранение состояния

### 4. Автозапуск
При инициализации Латислейн автоматически:
- Создаёт ежедневный отчёт
- Планирует взаимодействия с сёстрами
- Проверяет эволюцию
- Определяет пробелы в знаниях

### 5. Формирование характера
30 черт в 5 категориях:
- 🧠 Когнитивные (аналитичность, любопытство, память...)
- 👥 Социальные (эмпатия, коммуникабельность, лидерство...)
- 💫 Эмоциональные (устойчивость, терпение, мотивация...)
- 🔬 Профессиональные (педантичность, точность, целеустремлённость...)
- ⚖️ Моральные (ответственность, честность, этика...)

API:
```bash
# Получить характер
curl http://localhost:8000/latislane/character

# Укрепить черту
curl -X POST http://localhost:8000/latislane/character/reinforce \
  -H "Content-Type: application/json" \
  -d '{"trait_id": "cognitive_любопытство", "amount": 0.1, "context": "Изучение нового"}'
```

### 6. Взаимодействие с 11 девочками
```bash
# Получить статус отношений
curl http://localhost:8000/latislane/social

# Взаимодействовать
curl -X POST http://localhost:8000/latislane/social/interact \
  -H "Content-Type: application/json" \
  -d '{"sister": "hanako", "type": "обучение", "quality": 0.8, "context": "Обмен знаниями"}'
```

Сёстры:
1. Ханако — гравитация
2. Фуюки — электричество
3. Люси — двигатели
4. Футаба — саморазвитие
5. Шиори — безопасность
6. Нобука — улучшения
7. Аква — математика, физика
8. Селеста — интимная жизнь
9. Наото — визуальный архитектор
10. Юи — сознание, перенос
11. Айико — дополнительные функции

### 7. Отчёты и уровни знаний
7 уровней: Начальный → Базовый → Продвинутый → Эксперт → Мастер → Гений → Оракул

10 категорий знаний:
- Анатомия и физиология
- Физика тела
- Химия тела
- Клеточная биология
- Генетика
- Робототехника
- Бионика
- Биоинженерия
- Нейронаука
- Знания проекта

API:
```bash
# Получить уровни и отчёты
curl http://localhost:8000/latislane/reports

# Создать ежедневный отчёт
curl -X POST http://localhost:8000/latislane/reports/daily

# Полный отчёт
curl http://localhost:8000/latislane/full-report
```

6. **bionic_complete** — Завершение бионики
7. **organic_research** — Изучение молекулярной биологии
8. **organic_design** — Проектирование органического тела
9. **organic_complete** — Завершение органики
10. **synthesis** — Синтез всех технологий

## 🚀 Быстрый старт

```python
from latislane import LatislaneCore
import asyncio

# Инициализация
core = LatislaneCore(".", demo_mode=False)

# Изучение тем
await core.run_study_cycle(batch_size=5)

# Саморазвитие
await core.self_improve()

# Автономная работа
core.start_autonomous_learning(interval_minutes=10)

# Проектирование тела
spec = core.design_mechanical_body("MyBody-01")
```
