## 📞 Протоколы связи

### 1. ExchangeProtocol — Обмен данными

**Назначение:** Автоматический обмен теориями и данными между учёными.

**Как работает:**
- Каждые 5 циклов проверяет наличие новых теорий
- Копирует теории из state-файлов
- Уведомляет о новых данных

**Пример:**
```python
# Люси получает теории от Ханако и Фуюки
hanako_theories = exchange.get_theories_from("hanako")
fuyuki_theories = exchange.get_theories_from("fuyuki")
```

### 2. RequestProtocol — Запрос помощи

**Назначение:** Запрос помощи у сестёр или Нобуки.

**Типы запросов:**
- `theory_request` — Нужна новая теория
- `calculation_help` — Помощь с расчётами
- `code_review` — Проверка кода (Нобука)
- `validation` — Проверка теории (Нобука)

**Пример:**
```python
# Люси запрашивает помощь у Нобуки
request = RequestProtocol.create(
    from_scientist="lucy",
    to_scientist="nobuka",
    request_type="code_review",
    message="Проверь расчёт тяги двигателя"
)
```

### 3. CollaborationProtocol — Совместная работа

**Назначение:** Координация совместных исследований.

**Сценарии:**
- Совместное проектирование
- Перекрёстная проверка теорий
- Общие эксперименты

## ⚡ Экстренная связь с Нобукой

**Когда обращаться:**
- ❌ Ошибка в расчётах
- ❌ Нужен код-ревью
- ❌ Требуется тестирование
- ❌ Проблемы с производительностью
- ❌ Конфликт теорий

**Как обращаться:**
```python
from scientists_network import RequestProtocol

request = RequestProtocol.create(
    from_scientist="lucy",
    to_scientist="nobuka",
    request_type="urgent_help",
    message="Критическая ошибка в расчёте тяги!",
    priority="high"
)
```

**Нобука обязана ответить в течение 1 цикла!**
