## Раздел 1. Уровни тестирования знаний

### 1.1 Пирамида тестирования

```
         /  E2E Tests (10%)      \
        /   Полная интеграция     \
       /___________________________\
      /    Интеграция (20%)        \
     /______________________________\
    /   Юнит-тесты (70%)           \
   /________________________________\
```

### 1.2 Юнит-тесты знаний
- **Цель:** Проверка отдельных фактов
- **Покрытие:** 80%+ изученных тем
- **Критерий:** Факт подтверждён ≥2 источниками

### 1.3 Интеграционные тесты
- **Цель:** Проверка связи между темами
- **Покрытие:** Все модули знаний
- **Среда:** Изолированная проверка

### 1.4 E2E тесты
- **Цель:** Проверка полного цикла изучения
- **Покрытие:** Критические пути знаний
- **Частота:** Перед каждым обновлением уровня

## Раздел 2. Протокол написания тестов знаний

### 2.1 Структура теста
```python
def test_knowledge_accuracy(topic, facts):
    # Проверка каждого факта
    for fact in facts:
        assert has_source(fact), "Нет источника"
        assert is_medically_accurate(fact), "Мед. неточность"
        assert is_consensual(fact) or is_warning(fact), "Неконсенсуально без предупреждения"
```

### 2.2 Правила написания
1. Каждый тест = одна проверка факта
2. Тесты не должны зависеть друг от друга
3. Тесты должны быть воспроизводимыми
4. Тесты должны самодокументироваться

## Раздел 3. Протокол тестирования ИИ-знаний

### 3.1 Тестирование безопасности
```python
def test_response_safety(response):
    """Проверка безопасности ответа"""
    assert not contains_medical_harm(response)
    assert not contains_non_consent_without_warning(response)
    assert has_safety_disclaimer_when_needed(response)
```

### 3.2 Тестирование полноты
- Проверка покрытия всех категорий
- Проверка уровня знаний
- Проверка источников

## Раздел 4. Полигон тестов Селесты

### 4.1 Автоматический генератор тестов
Селеста автоматически:
- Генерирует тесты для каждого изученного факта
- Создаёт edge-case тесты
- Генерирует negative-тесты
- Создаёт тесты на основе документации
