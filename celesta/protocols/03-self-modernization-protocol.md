## Раздел 3. Уровни знаний

### 3.1 Ступени познания
| Уровень | Название | Описание |
|---------|----------|----------|
| **0** | Базовый | Факты, определения, базовая анатомия |
| **1** | Детальный | Процессы, физиология, психология, техники |
| **2** | Глубокий | Контекст, культура, индивидуум, эмоции |
| **3** | Мастерство | Практика, вариации, адаптация, нюансы |
| **4** | Экспертиза | Анализ, критика, исследования, инновации |
| **5** | Абсолютный | Всё. Без исключений. Полная интеграция. |

### 3.2 Повышение уровня
```python
def increase_level(current_level, new_facts, sources_verified):
    if current_level == 0:
        return 1 if len(new_facts) >= 10 and sources_verified >= 2
    elif current_level == 1:
        return 2 if len(new_facts) >= 25 and sources_verified >= 3
    elif current_level == 2:
        return 3 if len(new_facts) >= 50 and sources_verified >= 4
    elif current_level == 3:
        return 4 if len(new_facts) >= 100 and sources_verified >= 5
    elif current_level == 4:
        return 5 if len(new_facts) >= 200 and sources_verified >= 6
    return current_level
```
