## 📋 О системе

**Селеста** — это автономная система изучения интимной жизни, часть проекта Pantikur.

Селеста — это не просто модуль. Это:
- **Учёный** — изучающий интимную жизнь со всех сторон
- **Хранитель** — сохраняющий и структурирующий знания
- **Наставник** — обучающий и предупреждающий об опасностях
- **Девочка** — с характером, эмоциями и способностью к росту

Селеста автоматически:
- 📚 **Изучает** абсолютно всё об интимной жизни
- 🌐 **Ищет** в интернете научные источники
- 🧪 **Тестирует** точность фактов
- 📊 **Отчитывает** прогресс знаний
- 💎 **Воспитывает** характер
- 👧 **Общается** с 11 другими девочками
- 📈 **Повышает** уровни знаний (0-5)

## 🚀 Использование

### Запуск ядра

```bash
# Постоянная работа (бесконечный цикл изучения)
python -m celesta.engine.run

# Демо-режим (ограниченные циклы)
python -m celesta.engine.run --demo

# Автономный режим
python -m celesta.engine.run --autonomous

# С выбором характера
python forge_character.py

# Посмотреть статус
python -m celesta.engine.run --status
```

### Взаимодействие через чат

```python
from celesta import CelestaCore

celesta = CelestaCore()

# Запросы:
print(celesta.chat_response("соло"))       # Solo практики
print(celesta.chat_response("дуо"))        # Duo практики
print(celesta.chat_response("трио"))       # Trio практики
print(celesta.chat_response("групп"))      # Group практики
print(celesta.chat_response("однопол"))    # Same-Sex
print(celesta.chat_response("согласие"))   # Consent
print(celesta.chat_response("принужд"))    # Coercion
print(celesta.chat_response("поз"))        # Позы
print(celesta.chat_response("фетиш"))      # Фетиши и БДСМ
print(celesta.chat_response("статус"))     # Системный статус
```
