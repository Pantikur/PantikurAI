# 🌹 Celesta — Система изучения интимной жизни

**Celesta** — автономная система, изучающая интимную жизнь всех рас от прикосновений до последствий.

## 📚 Что изучает

### Этапы интимной жизни:

| Этап | Название | Описание |
|------|----------|----------|
| 1 | 🤚 Прикосновения | Виды, физиология, эффекты |
| 2 | 🔥 Возбуждение | Фазы, гормоны, психология |
| 3 | 💞 Интимный процесс | Физиология, репродукция |
| 4 | 😴 После интима | Окситоцин, восстановление |
| 5 | ⚠️ Избыточный интим | Последствия чрезмерности |
| 6 | 🚫 Прерванный процесс | Последствия прерывания |
| 7 | 📊 Последствия | Общие эффекты |
| 8 | 💤 Восстановление | Рефрактерный период, питание |
| 9 | 🌍 Полное понимание | Особенности по расам |

## 🧬 Модули знаний

1. **touch_system** — прикосновения и их виды
2. **arousal_system** — физиология возбуждения
3. **intimacy_process** — интимный процесс
4. **excessive_intimacy** — последствия избыточности
5. **interrupted_process** — последствия прерывания
6. **consequences_system** — общие последствия
7. **recovery_system** — восстановление
8. **race_specific_intimacy** — особенности рас

## 🌍 Особенности рас

- **Люди** — стандартная физиология, цикл 24-28 дней
- **Эльфы** — замедленный метаболизм, возбуждение ×2
- **Демоны** — выносливость ×3, рефрактерный ÷3
- **Нежить** — репродукция нет, сенсорика сохранена
- **Элементали** — энергетический обмен

## ⚠️ Последствия избыточного интима

1. Истощение цинка (3 мг за событие)
2. Гормональный дисбаланс (пролактин ↑ → тестостерон ↓)
3. Хроническая усталость
4. Повреждение тканей
5. Дофаминовая зависимость
6. Долгосрочный гормональный дисбаланс

## 🚫 Последствия прерванного процесса

1. Венозный застой (боль, давление 6-24ч)
2. Резорбция семенного материала
3. Психологический стресс
4. Ретроградная эякуляция
5. Хронический простатит
6. Нарушение условных рефлексов

## 🚀 Быстрый старт

### 1. Инициализация

```python
from celesta import CelestaCore

core = CelestaCore(project_root=".", demo_mode=True)
core.start_intimacy_study()
await core.run_study_cycle()
```

### 2. Получение отчёта

```python
report = core.get_intimacy_report()
print(f"Прогресс: {report['overall_progress']*100:.1f}%")
```

### 3. Чат с Селестой

```python
response = core.chat_response("какие последствия избыточного интима?")
print(response)
```

## 🌐 API Endpoints

Все эндпоинты доступны через `http://localhost:8000`

| Endpoint | Method | Описание |
|----------|--------|----------|
| `/celesta/status` | GET | Статус системы |
| `/celesta/intimacy` | GET | Отчёт по интимным знаниям |
| `/celesta/stage/{stage}` | GET | Детали этапа |
| `/celesta/consequences` | POST | Последствия сценария |
| `/celesta/race/{race}` | GET | Особенности расы |
| `/celesta/study` | POST | Запуск обучения |
| `/celesta/chat` | POST | Чат с Селестой |
| `/celesta/learn` | POST | Начать изучение |

### Примеры запросов

**Статус системы:**
```bash
curl http://localhost:8000/celesta/status
```

**Последствия избыточного интима:**
```bash
curl -X POST http://localhost:8000/celesta/consequences \
  -H "Content-Type: application/json" \
  -d '{"scenario": "excessive"}'
```

**Особенности эльфов:**
```bash
curl http://localhost:8000/celesta/race/elf
```

**Чат с Селестой:**
```bash
curl -X POST http://localhost:8000/celesta/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "расскажи о прикосновениях"}'
```
