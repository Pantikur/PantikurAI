## 📋 О системе

**Кристи** (クリスチ — «режиссёр», «визионер») — специалист по видеопроизводству, автономный режиссёр и продюсер.

Кристи автоматически:
- 🎬 **Управляет созданием видео** — от идеи до финального рендера
- 📋 **Пишет сценарии и раскадровки** — структурирует каждую сцену
- 🎨 **Координирует с Айка** — визуальный стиль, референсы, персонажи
- 🎭 **Режиссирует** — постановка камеры, свет, композиция кадров
- 🎵 **Работает со звуком** — музыка, звуковые эффекты, озвучка
- ✂️ **Монтирует** — склейки, переходы, тайминг
- 🎞️ **Анимация** — 2D и 3D анимация для видео
- 🌐 **Изучает интернет** — техники монтажа, тренды, инструменты
- 📝 **Документирует** — ведёт журнал производства
- 💪 **Развивает характер** — самостоятельно выбирает и выращивает свой характер
- 💬 **Общается с 12 сёстрами** — через Scientists Network

## 🎯 Функции Кристи

### 1. 🎬 Управление созданием видео
Кристи управляет полным циклом:
- Разработка концепции и идеи
- Написание сценария
- Создание раскадровки
- Постановка сцены
- Съёмка / генерация кадров
- Монтаж и постпродакшн
- Финальный рендер

### 2. 📋 Сценарии и раскадровки
Кристи:
- Пишет диалоги и описание сцен
- Создаёт тайминг кадров
- Определяет ракурсы камеры
- Планирует переходы
- Создаёт storyboard в текстовом/визуальном формате

### 3. 🎨 Координация с Айка
Кристи взаимодействует с Айка:
- Получает визуальные референсы
- Согласовывает стиль анимации
- Координирует создание персонажей
- Запрашивает фоны и декорации
- Обсуждает цветовую палитру

### 4. 🎭 Режиссура
Кристи:
- Ставит камеру (ракурсы, движения)
- Планирует свет и тени
- Определяет композицию кадра
- Управляет актёрской игрой (для анимации)
- Контролирует эмоциональную атмосферу

### 5. 🎵 Работа со звуком
Кристи:
- Подбирает музыкальное сопровождение
- Планирует звуковые эффекты
- Когенирует озвучку персонажей
- Синхронизирует звук с видео
- Балансирует аудиомикс

### 6. ✂️ Монтаж
Кристи:
- Склеивает сцены
- Добавляет переходы (fade, cut, wipe)
- Контролирует тайминг и ритм
- Добавляет титры и субтитры
- Корректирует цветокоррекцию

### 7. 🎞️ Анимация
Кристи:
- Планирует 2D анимацию
- Управляет 3D анимацией
- Синхронизирует анимацию с диалогами
- Создаёт переходные анимации
- Оптимизирует для рендера

### 8. 🌐 Изучение интернета
Кристи:
- Изучает техники видеомонтажа
- Анализирует тренды в видеоиндустрии
- Осваивает новые инструменты (DaVinci, Premiere, Blender)
- Изучает теорию режиссуры
- Анализирует работы лучших режиссёров

### 9. 📝 Документирование производства
Кристи:
- Ведёт журнал производства
- Документирует каждое решение
- Фиксирует технические параметры
- Составляет отчёты о прогрессе
- Архивирует этапы производства

### 10. 💪 Саморазвитие
Кристи:
- Создаёт характер при первом запуске
- Укрепляет сильные стороны
- Эволюционирует на основе опыта
- Перенимает черты у сестёр
- Записывает ценности и цели

### 11. 🌐 Выход в интернет
Кристи:
- Ищет обучающие материалы по видеопроизводству
- Изучает новые кодеки и форматы
- Анализирует тренды видеоиндустрии
- Изучает техники цветокоррекции
- Осваивает новые инструменты

### 12. 💬 Общение с 13 сёстрами
Кристи общается со всеми:
- Футаба — управление проектом
- Нобука — улучшения качества
- Шиори — безопасность контента
- Айка — визуальный стиль и референсы
- Селеста — анатомия для анимации
- Люси — учебные материалы
- Фуюки — исследования
- Латислейн — логика алгоритмов
- Наото — внимание к деталям
- Юи — когнитивные науки для повествования
- Ханако — творческое вдохновение
- Аква — математические расчёты для тайминга и пропорций

### 13. 📊 Повышение уровня знаний
Кристи:
- Растёт от Lvl 1 до Lvl 20
- Получает XP за каждый этап производства
- Изучает новые техники
- Копит знания о видеоиндустрии

## 🚀 Использование

### Запуск ядра

```bash
# Постоянная работа (бесконечный цикл производства)
python -m kristi.engine.run

# Демо-режим (5 циклов, короткие интервалы)
python -m kristi.engine.run --demo

# Только производство видео
python -m kristi.engine.run --produce

# Только сценарии и раскадровки
python -m kristi.engine.run --script

# Только анализ
python -m kristi.engine.run --analyze

# Посмотреть текущее состояние
python -m kristi.engine.run --status

# Посмотреть характер
python -m kristi.engine.run --character

# Посмотреть знания
python -m kristi.engine.run --knowledge

# Свои параметры
python -m kristi.engine.run --interval 10 --max-cycles 50
```

### Что делает ядро

```
ЦИКЛ АВТОНОМНОГО ПРОИЗВОДСТВА:
  1. Самопроверка по Конституции
  2. Планирование сцен (каждый цикл)
  3. Режиссура и постановка (каждый цикл)
  4. Координация с Айка (периодически)
  5. Монтаж и постпродакшн (периодически)
  6. Изучение интернета (периодически)
  7. Общение с сёстрами (периодически)
  8. Написание отчётов (периодически)
  9. Развитие характера (периодически)
  10. Получение знаний (каждый цикл)
  11. Сохранение состояния
```
