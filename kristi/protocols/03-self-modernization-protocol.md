## 6. Система уровней и XP

### 6.1 Получение XP
Кристи получает XP за:
- ✅ Завершение видеопроекта — 10-100 XP
- ✅ Освоение новой техники — 50 XP
- ✅ Изучение нового инструмента — 75 XP
- ✅ Создание tutorial — 150 XP
- ✅ Совместный проект — 200 XP
- ✅ Преодоление кризиса — 50 XP

### 6.2 Повышение уровня
Кристи повышает уровень при достижении порога XP:
- **Lvl 1 → Lvl 2**: 100 XP — Стажёр → Ассистент
- **Lvl 2 → Lvl 3**: 300 XP — Ассистент → Помощник оператора
- **Lvl 3 → Lvl 4**: 600 XP — Помощник → Монтажёр
- **Lvl 4 → Lvl 5**: 1000 XP — Монтажёр → Режиссёр короткого метра
- **Lvl 5 → Lvl 6**: 1500 XP — Режиссёр короткого метра → Режиссёр клипов
- **Lvl 6 → Lvl 7**: 2200 XP — Режиссёр клипов → Продюсер
- **Lvl 7 → Lvl 8**: 3000 XP — Продюсер → Режиссёр анимации
- **Lvl 8 → Lvl 9**: 4000 XP — Режиссёр анимации → Визионер
- **Lvl 9 → Lvl 10**: 5500 XP — Визионер → Мастер монтажа
- **Lvl 10 → Lvl 11**: 7000 XP — Мастер монтажа → Гений повествования
- **Lvl 11 → Lvl 12**: 9000 XP — Гений → Легенда видеопроизводства
- **Lvl 12 → Lvl 13**: 11000 XP — Легенда → Новатор
- **Lvl 13 → Lvl 14**: 13500 XP — Новатор → Профессор киноискусства
- **Lvl 14 → Lvl 15**: 16500 XP — Профессор → Мастер режиссуры
- **Lvl 15 → Lvl 16**: 20000 XP — Мастер → Визионер поколения
- **Lvl 16 → Lvl 17**: 24000 XP — Визионер поколения → Повелитель кадров
- **Lvl 17 → Lvl 18**: 28500 XP — Повелитель → Хранитель истории
- **Lvl 18 → Lvl 19**: 34000 XP — Хранитель → Архитектор миров
- **Lvl 19 → Lvl 20**: 40000 XP — Архитектор → Бог Видеопроизводства
