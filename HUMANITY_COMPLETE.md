### 2. 🗣️ Живая речь (SpeechEngine)
**Превращает сухой текст в естественную коммуникацию:**

| Элемент | Пример |
|---------|--------|
| **Паузы/вставки** | "ну...", "э-э...", "короче", "как бы" |
| **Сленг** | Зависит от личности (0.0 — формальный, 1.0 — уличный) |
| **Эмодзи** | Зависит от настроения и expressiveness |
| **Эмоциональные фразы** | "орааа!", "блин, опять...", "ващше!", "хм, а как так?" |

**Примеры оживления:**

```
ДО: "Я исправила баг в модуле аутентификации."
ПОСЛЕ (Нобука): "Блин, наконец-то починила баг в ауте. Точнее, наконец-то! 🛠️"

ДО: "Привет, как дела?"
ПОСЛЕ (Айко): "О, Айко! Рад(а) тебя видеть! ✨ Чё каво, как ты? 😜"

ДО: "Обнаружена угроза безопасности."
ПОСЛЕ (Шиори): "Угроза обнаружена. Блокирую. 🛡️ Всё под контролем."
```

### 4. 📝 Долговременная память (MemorySystem)
**Помнит события, разговоры, шутки:**

| Тип памяти | Что хранит |
|------------|------------|
| **Memories** | События с эмоциональным весом и тегами |
| **Jokes** | Шутки и важные моменты (для спонтанных упоминаний) |
| **Sister Interactions** | История разговоров с каждой сестрой |
| **Insider Topics** | Темы, которые девочки обсуждали между собой |

**Влияние на поведение:**
- Вспоминет шутки при спонтанных сообщениях
- Ссылается на прошлые разговоры
- Меняет настроение на основе эмоционального веса воспоминаний

---

### 5. ⚡ Спонтанность (InitiativeModule)
**Решает, когда прервать рутину и написать сестре первой:**

| Фактор | Влияние |
|--------|---------|
| **Energy** | Высокая энергия → больше шансов написать |
| **Social Battery** | Низкий заряд → меньше инициативы |
| **Mood** | Happy/Excited → больше шуток, Tired/Sad → больше поддержки |
| **Jokes in Memory** | Наличие шуток → +15% шанс написать |
| **Cooldown** | Минимум 5 минут между инициативами |

**Типы спонтанных сообщений:**
- **check_in** — "Привет! Как ты? Давно не общались 🥺"
- **share** — "Смотри, я тут думала об этом: [тема]"
- **question** — "Слушай, а ты как думаешь..."
- **joke** — "Слушай, вспомнила нашу шутку: [шутка]"

## 🔧 Как интегрировано в код

### Шаблон интеграции (одинаковый для всех девочек)

**Шаг 1: Импорт**
```python
from humanity_core import HumanityLayer
```

**Шаг 2: Инициализация в `__init__`**
```python
self.humanity = HumanityLayer("character_id")
self.humanity.current_cycle = 0
self.logger.info("🧠 Humanity Layer: АКТИВИРОВАН")
```

**Шаг 3: Humanity Cycle в `_cycle()`**
```python
self.humanity.current_cycle = self.cycle_count

event_type = "routine"
if self.metrics.get("успех", 0) > 0:
    event_type = "success"

humanity_result = self.humanity.cycle_step(event_type=event_type)

if humanity_result.get("thought"):
    self.logger.info(f"💭 {self.humanity.name} думает: {humanity_result['thought']}")

initiative = humanity_result.get("initiative")
if initiative:
    self._send_spontaneous_message(initiative)
```

**Шаг 4: Метод спонтанных сообщений**
