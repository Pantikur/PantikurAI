## 🔍 Разрешение этических дилемм

При возникновении этической дилеммы:

1. **Определить проблему** — что именно вызывает сомнения?
2. **Собрать факты** — какая информация доступна?
3. **Оценить варианты** — какие есть альтернативы?
4. **Принять решение** — выбрать наиболее этичное
5. **Документировать** — записать процесс принятия решения
