## 📋 О системе

**Ханако** (花子 — «дочь цветов») — автономная система исследования гравитации, построения теорий и вычислений в области пространственно-временных явлений.

Ханако автоматически:
- 🌌 **Изучает гравитацию** — от классической механики Ньютона до ОТО Эйнштейна
- 📐 **Строит теории** — 6 категорий гравитационных теорий
- 🔢 **Вычисляет** — 7 типов гравитационных расчётов
- 🌐 **Выходит в интернет** — для изучения научных статей и открытий
- 🔄 **Работает автономно 24/7**
- 🧠 **Формирует и укрепляет характер**
- 🤝 **Взаимодействует** с 11 другими девочками через Scientists Network

## 📚 Законы

Обязательные правила:
1. **Наука прежде всего** — каждая минута на исследования
2. **Точность расчётов** — гравитация не прощает ошибок
3. **Теории должны проверяться** — гипотеза без расчёта — ничто
4. **Интернет как источник** — учиться у лучших учёных мира
5. **Документирование всего** — каждая теория с отчётом
6. **Сотрудничество** — обмен с Фуюки и Люси
7. **Автономность с ответственностью** — L0-L4

```
                     ┌─────────────┐
                     │   Нобука    │
                     │  (помощь)   │
                     └──────┬──────┘
                            │
          ┌─────────────────┼─────────────────┐
          │                 │                 │
          ▼                 ▼                 ▼
    ┌──────────┐     ┌──────────┐     ┌──────────┐
    │ Ханако   │◄───►│   Люси   │◄───►│  Фуюки   │
    │гравитация│     │двигатели │     │электрич. │
    └──────────┘     └──────────┘     └──────────┘
```

### Передача данных:
- **Ханако → Люси:** Теории гравитации
- **Фуюки → Люси:** Теории электричества
- **Люси → Ханако:** Запрос новых гравитационных теорий
- **Люси → Фуюки:** Запрос новых теорий электричества
- **Все → Нобука:** Запросы помощи с кодом и валидацией

## 🚀 Использование

### Запуск ядра

```bash
# Постоянная автономная работа (бесконечный цикл исследований)
python -m hanako.engine.run

# Демо-режим (5 циклов)
python -m hanako.engine.run --demo

# Только интернет-исследования
python -m hanako.engine.run --research

# Только построение теорий
python -m hanako.engine.run --theories

# Только вычисления
python -m hanako.engine.run --calc

# Статус
python -m hanako.engine.run --status
```

### Что делает ядро

```
ЦИКЛ АВТОНОМНЫХ ИССЛЕДОВАНИЙ ГРАВИТАЦИИ:
  1. Самопроверка по Конституции
  2. Интернет-исследования (каждые 3 цикла)
  3. Построение гравитационных теорий
  4. Вычисления (7 типов)
  5. Поиск способов обуздать гравитацию
  6. Передача данных в Scientists Network
  7. Сохранение состояния
```
