## Взаимодействие с сервером
- **Heartbeat:** Отправка статуса каждые 60 секунд
- **State Sync:** Синхронизация состояния при изменениях
- **Report:** Ежедневные отчёты о производительности
- **Config:** Получение обновлений конфигурации
- **API:** REST/gRPC интерфейс для внешних систем

## Протокол коммуникации
```python
# Отправка сообщения девочке
sidney.engine.communication.send(
    target="celesta",
    type="render_data",
    data={
        "fps": 60,
        "draw_calls": 1200,
        "triangles": 500000
    }
)

# Получение запроса от сервера
response = sidney.engine.communication.wait_for_request(timeout=5.0)

# Отправка отчёта
sidney.engine.communication.send_report(
    server=True,
    sisters=["celesta", "fuyuki", "nobuka"],
    report_type="daily_performance"
)
```
