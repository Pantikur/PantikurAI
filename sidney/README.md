# Сидни (Sidney) — 13-я Девочка-Учёный

## 🎮 Игровой Движок Полный Цикл

**Сидни** — 13-я девочка-учёный в сети, главный инженер игрового движка.

### Что делает Сидни

Сидни управляет **8 игровыми движками**:

| # | Движок | Описание |
|---|--------|----------|
| 1 | 🎨 **Графический** | 2D/3D рендерер, PBR, текстуры, освещение, спецэффекты |
| 2 | ⚙️ **Физический** | Гравитация, столкновения, разрушения, жидкости, ткани |
| 3 | 🔊 **Аудиодвижок** | 3D пространственный звук, музыка, DSP эффекты |
| 4 | 🎭 **Анимация** | Скелетная анимация, морфинг, физика волос/одежды, IK |
| 5 | 🤖 **ИИ** | NPC поведение, навигация (A*), принятие решений, группы |
| 6 | 🌐 **Сеть** | Мультиплеер, репликация, предикция, матчмейкинг |
| 7 | 📜 **Скрипты** | Lua/Python, node-based визуальное программирование, hot reload |
| 8 | 🏗️ **Редактор** | WYSIWYG уровень, ландшафт, освещение, префабы, экспорт |

### 🧠 Саморазвитие

- **Полная автономность** (L3) — принимает решения самостоятельно
- **Самостоятельный выбор характера** — 8 измерений, эволюция со временем
- **Повышение знаний** — 12 направлений, уровни 0-5, непрерывный рост
- **Цикл саморазвития** — анализ → планирование → реализация → тестирование → развёртывание → рефлексия

### 🚀 Запуск

```python
from sidney import SidneyCore

# Создание и инициализация
sidney = SidneyCore(project_root=".", demo_mode=True)
sidney.initialize()

# Запуск автономной работы
sidney.start()

# Получение статуса
status = sidney.get_status()
print(f"FPS: {status['engines']['fps']}")
print(f"Знания: {status['overall_knowledge_level']}")
print(f"Характер: {status['character']['name']}")

# Остановка
sidney.stop()
```
