# Деплой системы знаний

Этот документ описывает процесс развертывания системы долгосрочного обучения чат-бота.

## Требования

- Python 3.8 или выше
- PyTorch
- joblib
- numpy
- requests
- beautifulsoup4
- torch

Убедитесь, что основные зависимости установлены:
```bash
pip install -r requirements.txt
```

## Шаг 1: Инициализация системы

Запустите скрипт инициализации, который создаст все необходимые директории и файлы:

```bash
python scripts/init_knowledge_system.py
```

Этот скрипт:
- Создаст директорию `data/knowledge/`
- Создаст необходимые файлы для системы знаний
- Проверит наличие основных компонентов

## Шаг 2: Проверка файлов

Убедитесь, что все необходимые файлы присутствуют в проекте:

```
Pantikur/
├── knowledge_manager.py
├── update_knowledge.py
├── scripts/auto_learn_cycle.py
├── init_knowledge_system.py
├── knowledge_system_README.md
├── DEPLOYMENT.md
├── requirements_knowledge.txt
├── Wuglarst/src/chatbot.py (модифицированная версия)
├── retrain.py
├── train.py
└── data/
    └── knowledge/  # Будет создана автоматически
```

## Шаг 3: Запуск чат-бота

Запустите чат-бота, чтобы начать накопление знаний:

```bash
python -m Wuglarst.src.chatbot
```

Бот начнет:
- Отвечать на вопросы
- Искать определения неизвестных слов через WebSearch
- Сохранять новые слова и их определения в систему знаний

## Шаг 4: Цикл обучения

Существует три варианта организации цикла обучения:

### Вариант A: Ручное обновление (рекомендуется для тестирования)

```bash
# 1. Обновить систему знаний и сгенерировать обучающие пары
python scripts/update_knowledge.py

# 2. Запустить ретраин модели
python retrain.py
```

### Вариант B: Автоматический цикл (рекомендуется для продакшена)

```bash
# Запустить автоматический цикл обучения
python scripts/auto_learn_cycle.py
```

Этот скрипт будет автоматически:
- Проверять наличие новых знаний каждые 5 минут
- Запускать ретраин при накоплении достаточного количества новых слов
- Вести логирование процесса в `auto_learn.log`

### Вариант C: Расписание (для продвинутого использования)

Используйте системный планировщик задач:

**Linux/Mac (cron):**
```bash
# Проверять каждые 30 минут
*/30 * * * * cd /path/to/project && python scripts/update_knowledge.py && python retrain.py
```

**Windows (Task Scheduler):**
Создайте задачу, которая запускает:
```
python scripts/update_knowledge.py
python retrain.py
```

## Шаг 5: Мониторинг и диагностика

### Просмотр статистики

```python
from Wuglarst.src.chatbot import ChatBot

# Инициализируем бота
bot = ChatBot("models/chat_model.pth", "data/chat_data.pkl")

# Просмотр отчета о знаниях
bot.get_knowledge_report()
```

### Просмотр логов

- `auto_learn.log` - логи автоматического цикла обучения
- Консольный вывод - информация о процессе обучения

### Файлы данных

- `data/knowledge/learned_words.json` - выученные слова и определения
- `data/knowledge/training_pairs.jsonl` - обучающие пары для ретраина
- `data/knowledge/knowledge_stats.json` - статистика знаний
- `data/knowledge/learning_status.json` - статус цикла обучения
- `data/user_conversations.jsonl` - пользовательские диалоги

## Шаг 6: Интеграция с существующей системой

### Обновление chatbot.py

Убедитесь, что используется модифицированная версия `Wuglarst/src/chatbot.py`, которая:
- Импортирует `KnowledgeManager`
- Сохраняет знания из WebSearch
- Интегрируется с системой ретраина

### Проверка retrain.py

Убедитесь, что `retrain.py` использует обновленный файл `data/user_conversations.jsonl`, который теперь содержит:
- Пользовательские диалоги
- Сгенерированные обучающие пары из знаний

## Устранение неполадок

### Проблема: Не найден модуль knowledge_manager

**Решение:**
Убедитесь, что `knowledge_manager.py` находится в корне проекта и что вы запускаете скрипты из правильной директории:

```bash
cd /path/to/project
python scripts/update_knowledge.py
```

### Проблема: Ошибки при ретраине

**Решение:**
1. Проверьте, что `data/user_conversations.jsonl` существует
2. Убедитесь, что в файле есть данные
3. Проверьте права на запись в директории

### Проблема: WebSearch не находит определения

**Решение:**
1. Проверьте интернет-соединение
2. Убедитесь, что веб-сайты словарей доступны
3. Проверьте User-Agent в `web_search.py`

## Рекомендации

1. **Регулярное резервное копирование** - регулярно копируйте `data/knowledge/` и `models/`
2. **Мониторинг ресурсов** - ретраин может потреблять значительные вычислительные ресурсы
3. **Тестирование** - перед запуском в продакшене протестируйте систему на небольшом наборе данных
4. **Постепенное развертывание** - начните с ручного цикла, затем переходите к автоматическому

## Поддержка

При возникновении проблем:
1. Проверьте логи
2. Убедитесь, что все файлы на месте
3. Проверьте зависимости
4. Обратитесь к документации в `knowledge_system_README.md`
