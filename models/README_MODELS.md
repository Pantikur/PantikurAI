# Распределение моделей

## 📊 Архитектура

```
┌─────────────────────────────────────────────────────────┐
│                    ПРИОРИТЕТ МОДЕЛЕЙ                     │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  🤖 ОСНОВНОЙ БОТ (main.py, Wuglarst)                   │
│     → Qwen2.5-3B (универсальная)                        │
│     → Размер: 6 ГБ                                      │
│     → Использует: все функции бота                      │
│                                                         │
│  🔧 НОБУКА (nobuka/)                                   │
│     → Qwen2.5-Coder-3B (только для программирования)    │
│     → Размер: 6 ГБ                                      │
│     → Использует: анализ кода, генерация, рефакторинг   │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 🎯 Зачем две модели?

| Модель | Для чего | Плюсы |
|--------|----------|-------|
| **Qwen2.5-3B** | Основной бот, чат, диалоги | Универсальная, знает книги, мир Вугларст, эмоции |
| **Qwen2.5-Coder-3B** | Только Нобука (программист) | Отлично знает Python, паттерны, антипаттерны, отладку |

## 📁 Файлы

```
models/
├── qwen2.5-3b/              ← Основная модель (для main.py)
├── qwen2.5-coder-3b/        ← Coder модель (только для Нобуки)
└── rugpt3_vuglarst/         ← Дообученная ruGPT3 (fallback)
```

## 🚀 Как скачать

### 1. Основная модель (если ещё не скачана):
```bash
python download_qwen_model.py
```

### 2. Coder модель для Нобуки:
```bash
python download_coder_model.py
```

## ⚙️ Конфигурация

### main.py (основной бот)
- Приоритет: `models/qwen2.5-3b`
- Coder модель НЕ используется

### Wuglarst/src/chatbot.py (чат-бот)
- Приоритет: `models/qwen2.5-3b`
- Coder модель НЕ используется

### nobuka/engine/nobuka_core.py (Нобука)
- Приоритет: `models/qwen2.5-coder-3b`
- Использует Coder модель для:
  - Анализа кода
  - Генерации кода
  - Поиска багов
  - Рефакторинга

## 📊 Метрики

| Модель | Размер | RAM (CPU) | RAM (GPU 4-bit) |
|--------|--------|-----------|-----------------|
| Qwen2.5-3B | 6 ГБ | 8 ГБ | 4 ГБ |
| Qwen2.5-Coder-3B | 6 ГБ | 8 ГБ | 4 ГБ |

**Общий расход:** ~12 ГБ (если обе скачаны)

## 🔧 Использование в коде

### Для основного бота (main.py):
```python
# Использует Qwen2.5-3B автоматически
# Путь: models/qwen2.5-3b
```

### Для Нобуки (nobuka_core.py):
```python
# Использует Qwen2.5-Coder-3B автоматически
# Путь: models/qwen2.5-coder-3b

# Публичный метод:
response = nobuka_core.generate_coder_response("Проанализируй этот код...")
```

## 📝 Примечания

1. **Обе модели можно скачать одновременно** — они занимают ~12 ГБ вместе
2. **Coder модель быстрее** в задачах программирования (в 2-3 раза)
3. **Основная модель лучше** в диалогах и общих вопросах
4. **Если Coder модель не скачана** — Нобука работает без неё (только анализ кода)
