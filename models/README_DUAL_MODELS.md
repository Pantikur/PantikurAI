# 🤖 Нобука — Две модели для максимальной эффективности

## 📊 Что изменилось?

Нобука теперь использует **две модели** вместо одной:

| Модель | Для чего | Размер |
|--------|----------|--------|
| **Qwen2.5-Coder-3B** | Программирование, код, баги, рефакторинг | 6 ГБ |
| **Qwen2.5-3B** | Диалоги, эмоции, общие вопросы | 6 ГБ |

## 🎯 Как это работает?

### Автоматический выбор модели

Нобука **сама определяет** тип задачи и выбирает модель:

```python
# Пример 1: Задача программирования → Coder
response = nobuka_core.generate_response("Как исправить баг в этом коде?")
# → Использует Qwen2.5-Coder-3B

# Пример 2: Диалог → General
response = nobuka_core.generate_response("Привет, как дела?")
# → Использует Qwen2.5-3B

# Пример 3: Задача программирования → Coder
response = nobuka_core.generate_response("def calculate_sum(a, b): return a + b")
# → Использует Qwen2.5-Coder-3B
```

### Ключевые слова для Coder модели:
- `код`, `python`, `функция`, `класс`, `метод`, `баг`, `ошибка`
- `дебаг`, `отладк`, `рефакт`, `паттерн`, `алгоритм`, `оптимиз`
- `импорт`, `синтакс`, `async`, `def `, `class `, `import `
- `программ`, `скрипт`, `модуль`, `api`, `фреймворк`, `библиотека`
- `тест`, `pytest`, `unittest`, `coverage`, `lint`, `pypi`
- `github`, `git`, `коммит`, `ветк`, `merge`, `pull request`

### Ключевые слова для General модели:
- Всё что не относится к программированию
- Диалоги, эмоции, консультации
- Взаимодействие с сёстрами

## 📁 Структура

```
models/
├── qwen2.5-3b/              ← General модель (универсальная)
├── qwen2.5-coder-3b/        ← Coder модель (для кода)
└── rugpt3_vuglarst/         ← Fallback
```

## ⚙️ API

### 1. Автоматический выбор (рекомендуется):
```python
response = nobuka_core.generate_response(prompt)
# Нобука сама выбирает модель
```

### 2. Принудительное использование Coder:
```python
response = nobuka_core.generate_coder_response(prompt)
# Всегда использует Coder модель
```

### 3. Проверка доступности моделей:
```python
# Проверить Coder
if hasattr(nobuka_core, 'coder_model') and nobuka_core.coder_model is not None:
    print("✅ Coder модель доступна")

# Проверить General
if hasattr(nobuka_core, 'general_model') and nobuka_core.general_model is not None:
    print("✅ General модель доступна")
```

## 📊 Преимущества

| Возможность | Одна модель | Две модели |
|-------------|-------------|------------|
| Код Python | ✅ Хорошо | ✅✅ Отлично (Coder) |
| Диалоги | ✅ Хорошо | ✅✅ Лучше (General) |
| Эмоции | ⚠️ Частично | ✅✅ Отлично (General) |
| Отладка | ⚠️ Частично | ✅✅ Отлично (Coder) |
| Паттерны | ⚠️ Частично | ✅✅ Отлично (Coder) |

## 🚀 Установка

### 1. Скачать обе модели:
```bash
python download_qwen_model.py
python download_coder_model.py
```

### 2. Перезапустить бота:
```bash
python main.py
```

## 📝 Примечания

1. **Обе модели загружаются автоматически** при старте Нобуки
2. **Выбор модели происходит автоматически** на основе ключевых слов
3. **Если одна модель не найдена** — Нобука использует другую
4. **Общий расход места:** ~12 ГБ (6+6 ГБ)
5. **Общий расход RAM:** ~16 ГБ (8+8 ГБ на CPU) или ~8 ГБ (4+4 ГБ на GPU с 4-bit)
