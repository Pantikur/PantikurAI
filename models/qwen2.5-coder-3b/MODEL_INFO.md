## ⚙️ Использование

### В Нобуке (nobuka/engine/nobuka_core.py):
```python
# Автоматически загружается при старте Нобуки
# Путь: models/qwen2.5-coder-3b

# Публичный метод для генерации кода:
response = nobuka_core.generate_coder_response("Проанализируй этот код...")
```

### В основном боте:
- **НЕ используется**
- Основной бот использует `models/qwen2.5-3b`
