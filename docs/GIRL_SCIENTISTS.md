## 🌸 Ханако — Исследователь гравитации

### Миссия
Изучить гравитацию, построить теории, вычислить возможности и найти способ обуздать гравитацию.

### Структура
```
hanako/
├── constitution.md              # Конституция
├── laws/01-core-laws.md         # 7 законов гравитации
├── codes/01-ethics-code.md      # Кодекс этики
├── README.md                    # Документация
└── engine/
    ├── config.py                # Конфигурация
    ├── models.py                # Модели данных
    ├── hanako_core.py           # Ядро
    ├── web_access.py            # Интернет-доступ
    ├── theorist.py              # Построение теорий
    ├── calculator.py            # Вычисления
    └── run.py                   # Точка входа
```

### Компоненты

**1. Исследователь гравитации**
- Сканирует интернет на предмет гравитационных исследований
- Анализирует научные статьи (LIGO, квантовая гравитация, ОТО)
- Изучает эксперименты

**2. Построитель теорий**
- Создаёт гравитационные теории (6 категорий)
- Проверяет совместимость с физикой
- Оценивает научную ценность

**3. Вычислитель**
- 7 типов вычислений:
  - Гравитационная сила
  - Вторая космическая скорость
  - Орбитальный период
  - Гравитационное замедление времени
  - Радиус Шварцшильда
  - Гравитационные волны
  - Антигравитация (гипотетическая)

**4. Интернет-доступ**
- Поиск научных статей
- Мониторинг новых открытий
- Кэширование данных

### Запуск

```bash
# Постоянная работа
python -m hanako.engine.run

# Демо-режим (5 циклов)
python -m hanako.engine.run --demo

# Только изучение в интернете
python -m hanako.engine.run --research

# Только построение теорий
python -m hanako.engine.run --theories

# Только вычисления
python -m hanako.engine.run --calc

# Статус
python -m hanako.engine.run --status
```

### Метрики
- `theories_built` — Построено теорий
- `calculations_run` — Выполнено вычислений
- `papers_studied` — Изучено статей
- `web_searches` — Поисков в интернете
- `gravity_secrets_found` — Найдено секретов гравитации
