## Scientists Network

### Возможности
- **Peer-to-peer**: прямые сообщения между учёными
- **Broadcast**: групповые сообщения
- **Data transfer**: передача теорий, вычислений, проектов
- **Coordination**: координация совместной работы
- **Auto-chat**: автоматическая болтовня (10% шанс)
- **Internet**: Аква и Юи могут искать данные в интернете

### Типы сообщений
- `greeting` — приветствия
- `message` — обычные сообщения
- `question` / `answer` — вопросы и ответы
- `theory` — научные теории
- `calculation` — вычисления
- `improvement` — улучшения
- `consciousness` — модели сознания (Юи)
- `mind_upload` — перенос разума (Юи)
- `soul_digitization` — оцифровка души (Юи)
- `boredom` — автоматическая болтовня
- `coordination` — координация

## API Endpoints

### Research Monitor
- `GET /research/status` — статус всех ядер
- `GET /research/{scientist}/summary` — сводка по ядру
- `GET /research/{scientist}/events` — события ядра
- `GET /research/{scientist}/data` — данные Юи
- `GET /research/live/{scientist}` — SSE поток

### Scientists Network
- `GET /network/status` — статус сети
- `GET /network/history` — история сообщений
- `POST /network/send` — отправить сообщение

## Примеры коммуникации

### Юи делится моделью сознания
```
[CONSCIOUSNESS] yu → all
🧠 Новая модель сознания: Квантовое сознание
```

### Аква с интернетом
```
[CALCULATION] akva → all
🧮 Вычисление: E=mc^2 = 9×10^16 J

📚 Найдена статья: 'quantum gravity latest research' - 15 результатов
```

### Координация
```
[COORDINATION] lucy → hanako
🤝 Ханако, нужны твои теории гравитации для двигателя!
```

### Автоматическая болтовня
```
[BOREDOM] futaba → all
😴 Мне немного скучно... Кто-нибудь хочет поболтать?

[CHAT] shiori → futaba
🎉 Не скучай! Давай обсудим мои последние результаты!
```

## Уровень автономности

- **L0-L1**: Требует подтверждения для каждого действия
- **L2**: Автономная работа с логированием
- **L3**: Полная автономия в рамках заданных направлений
- **L4**: Самостоятельное определение новых направлений

Все учёные работают на **L3** — полная автономия в рамках своих направлений.
