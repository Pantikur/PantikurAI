## 🚀 Использование

### Запуск автообучения
```bash
# Непрерывно (каждые 10 минут)
python utils/auto_book_learning.py

# Одиночный цикл
python utils/auto_book_learning.py --once

# С настройками
python utils/auto_book_learning.py --cycle 15 --books 10
```

### Переменные окружения (.env)
```bash
AUTO_BOOK_LEARNING=true
AUTO_BOOK_LEARNING_CYCLE=10        # минут
AUTO_BOOK_MAX_BOOKS=5              # книг за цикл
```
