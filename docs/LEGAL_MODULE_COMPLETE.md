# ⚖️ Юридический модуль Футабы — Полная документация

## Обзор

Футаба теперь включает **юридический модуль** для изучения и мониторинга законодательства, правовых норм, регулирования ИИ и авторского права.

---

## Возможности

### 1. 📜 Изучение законодательства об ИИ

**Поддерживаемые юрисдикции:**
- 🇷🇺 Россия (264-ФЗ, Стратегия ИИ, 152-ФЗ)
- 🇪🇺 Евросоюз (AI Act, GDPR)
- 🇺🇸 США (Executive Order, NIST Framework)
- 🌍 Международное (OECD, UNESCO)

**Что изучается:**
- Определения и классификации ИИ
- Требования к разработчикам и пользователям
- Этические принципы
- Национальные стратегии развития
- Регуляторные требования

### 2. 📚 Авторское право

**Темы:**
- AI-генерированный контент
- Данные для обучения моделей
- Добросовестное использование (Fair Use)
- Сравнительный анализ по странам

**Примеры:**
- США: Thaler v. Perlmutter (2023) — только человеческое творчество
- Китай: Тиньичань vs Лянься — AI-контент защищён
- ЕС: Требуется человеческое участие
- РФ: Неоднозначно, требует творческого характера

### 3. 📋 Лицензии ПО и ИИ

**Изученные лицензии:**
- MIT License
- Apache 2.0
- GPL v3
- CC0 (Public Domain)
- OpenRAIL-M (для ИИ)

**Анализ:**
- Разрешения и условия
- Ограничения ответственности
- Совместимость лицензий
- Рекомендации по выбору

### 4. 🔍 Мониторинг изменений

**Отслеживает:**
- Новые законы и поправки
- Судебные решения
- Регуляторные обновления
- Требования по compliance

### 5. ⚖️ Анализ правовых рисков

**Категории рисков:**
- Защита данных (152-ФЗ, GDPR)
- Регулирование ИИ (264-ФЗ, AI Act)
- Авторское право
- Ответственность
- Контрактные риски

**Output:**
- Детальный анализ по категориям
- Рекомендации по устранению
- Статус compliance
- Чек-листы

### 6. 📊 Отчёты о соответствии

**Включает:**
- Сводку по изученным законам
- Критические проблемы
- Статус compliance по категориям
- Действия с дедлайнами


## База данных законов

### Изученные законы РФ

1. **264-ФЗ "Об ИИ" (2024)**
   - Определение понятия ИИ
   - Классификация по уровням риска
   - Требования к разработчикам
   - Национальная система маркировки

2. **Стратегия развития ИИ (2024)**
   - Цели развития до 2030 года
   - Приоритетные направления
   - Этические принципы

3. **152-ФЗ о персональных данных**
   - Согласие на обработку
   - Локализация баз данных
   - Трансграничная передача

### Изученные законы ЕС

1. **EU AI Act (2024)**
   - Классификация по рискам
   - Запрет определённых практик
   - Требования к высокому риску
   - Надзор после выхода на рынок

2. **GDPR (2018)**
   - Право на объяснение решений ИИ
   - Автоматизированное принятие решений
   - Dataprotection by design

### Изученные законы США

1. **Executive Order on Safe AI (2023)**
   - Стандарты безопасности
   - Защита приватности
   - Предотвращение дискриминации

2. **NIST AI RMF (2023)**
   - Фреймворк управления рисками
   - Картирование процессов

### Международные документы

1. **OECD AI Principles (2019)**
   - Инклюзивный рост
   - Справедливость и прозрачность
   - Надёжность и безопасность

2. **UNESCO Recommendation (2021)**
   - Ценности и принципы
   - Жизненный цикл ИИ
   - Международное сотрудничество
