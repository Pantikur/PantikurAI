## 📋 О модуле

**Аква** — научный модуль проекта Pantikur, специализирующийся на точных науках.

Аква — это не просто калькулятор. Это **учёный с характером**, который:
- 📚 Изучает математику, физику, аэродинамику и сопротивление материалов
- 🌐 Выходит в интернет за научными данными
- 🧠 Самостоятельно выбирает направления развития
- 💬 Общается с другими модулями-«девочками»
- 📝 Пишет научные отчёты
- 🌱 Растит свой характер и уровень знаний
- ⚡ Работает автономно в бесконечном цикле

|----------|----------|
| Любознательность | Жажда знаний |

| Уверенность | Уверенность в расчётах |
| Эмпатия | Понимание других модулей |

### Опыт и уровни

Каждое действие даёт XP:
- Изучение простой темы: +10 XP
- Изучение сложной темы: +25 XP
- Построение теории: +30 XP
- Расчёт: +15 XP
- Интернет-исследование: +20 XP
- Общение: +10 XP
- Совместный проект: +40 XP

Уровни: 1 (Новичок) → 100 (Легенда)

## 🚀 Использование

### Запуск ядра

```bash
# Постоянная работа (бесконечный цикл)
python -m akva.engine.run

# Демо-режим (10 циклов, короткие интервалы)
python -m akva.engine.run --demo

# Свои параметры
python -m akva.engine.run --interval 5 --max-cycles 50

# Отключить интернет
python -m akva.engine.run --no-web

# Отключить общение
python -m akva.engine.run --no-communication

# Отключить отчёты
python -m akva.engine.run --no-reports

# Показать статус
python -m akva.engine.run --status
```

### Запуск через main.py

```bash
# Все модули
python run.py

# Только Аква
python run.py --girls akva
```
