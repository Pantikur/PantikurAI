---

## 1. Типы отчётов

### 1.1 Цикловой отчёт (каждый цикл)
Краткий отчёт о проделанной работе:

```markdown
# Отчёт Аквы — Цикл #142
## Дата: 2026-07-14

### Изучено
- Математика: Уравнения Навье-Стокса (уровень 42 → 45)
- Физика: Квантовая запутанность (уровень 35 → 38)

### Построенные теории
1. Обобщённое дифференциальное уравнение для турбулентного потока
2. Модель связи числа Маха и подъёмной силы

### Вычисления
- Подъёмная сила крыла: 15,432 N (формула: L = Cl × 0.5 × ρ × v² × S)
- Число Рейнольдса: 2.3 × 10^6

### Общение
- Отправила данные по аэродинамике Люси
- Обсудила квантовую механику с Ханако

### Характер (изменения)
- Любознательность: 0.80 → 0.82 (+0.02)
- Точность: 0.90 → 0.91 (+0.01)

### Планы на следующий цикл
- Изучить теорию упругости
- Посчитать нагрузки на крыло
- Ответить на запрос Юи о нейросетях
```

### 1.2 Отчёт о теории
Подробное описание построенной теории.

### 1.3 Отчёт о расчёте
Детальный расчёт с формулами и данными.

### 1.4 Ежедневный отчёт (каждые 10 циклов)
Сводка за день с анализом прогресса.

### 1.5 Итоговый отчёт (каждые 50 циклов)
Глобальный анализ прогресса, характера, уровней.

---

## 2. Структура отчёта

### 2.1 Обязательные поля
- timestamp — время
- cycle — номер цикла
- area — область исследования
- topics — изученные темы
- theories — построенные теории
- calculations — выполненные вычисления
- communication — общение с модулями
- personality_changes — изменения характера
- xp_gained — полученный опыт
- level_changes — изменения уровней

### 2.2 Хранение
```
data/reports/
├── akva_cycle_142.json
├── akva_cycle_143.json
└── ...
```

---

## 3. Генерация отчётов

### 3.1 Автоматическая генерация
Каждый цикл Аква автоматически:
1. Собирает все результаты цикла
2. Формирует цикловой отчёт
3. Сохраняет в data/reports/
4. Отправляет краткую сводку другим модулям

### 3.2 Сводка для других модулей
Короткое сообщение с основными результатами:

```
📐 Аква → ВСЕ
Цикл #142 | +3 теории | +7 вычислений | +15 XP
Изучено: Навье-Стокса, квантовая запутанность
Отчёт: data/reports/akva_cycle_142.json
```
