## 1. Выбор направления

### 1.1 Приоритеты выбора
Каждый цикл Аква выбирает направление на основе:
- Текущих уровней знаний (слабые области приоритетны)
- Вектора характера (любознательность влияет на выбор)
- Запросов от других модулей
- Актуальности научных тем

### 1.2 Алгоритм выбора
```
1. Оценить текущие уровни знаний
2. Найти область с наименьшим уровнем
3. Если разница < 10 — учесть характер (любознательность)
4. Если есть запрос от модуля — приоритет этой теме
5. Проверить интернет на новые исследования
6. Выбрать конкретную тему
```

## 2. Изучение материала

### 2.1 Этапы изучения
1. **Поиск** — через интернет (arXiv, Wikipedia, образовательные ресурсы)
2. **Анализ** — понимание основных концепций
3. **Систематизация** — структурирование знаний
4. **Практика** — решение задач, расчёты
5. **Закрепление** — запись в базу знаний

### 2.2 Источники
- arXiv.org — научные статьи
- Wikipedia — базовые понятия
- Khan Academy — обучающие материалы
- MIT OpenCourseWare — курсы
- Литература проекта (knigi/) — книги по темам

## 3. Построение теорий

### 3.1 Процесс
1. Сформулировать гипотезу на основе изученного
2. Проверить через математические вычисления
3. Сравнить с известными данными
4. Записать теорию с описанием и доказательствами

### 3.2 Формат теории
```json
{
  "name": "Название теории",
  "category": "mathematics|physics|aerodynamics|strength_of_materials",
  "scientific_value": 0.85,
  "description": "Описание",
  "formulas": ["формула 1", "формула 2"],
  "evidence": ["доказательство 1", "доказательство 2"],
  "created_at": "2026-07-14T10:00:00"
}
```

## 4. Выполнение вычислений

### 4.1 Типы вычислений
- **Аналитические** — точные решения формул
- **Численные** — приближённые решения (метод Монте-Карло, конечные элементы)
- **Экспериментальные** — расчёты на основе данных

### 4.2 Верификация
Перед сохранением результата:
1. Проверить размерность
2. Проверить порядок величины
3. Сравнить с эталонным значением (если есть)
4. Записать формулу и условия

## 5. Запись в базу знаний

### 5.1 Структура
```
data/knowledge/
├── mathematics/     # Математика
├── physics/         # Физика
├── aerodynamics/    # Аэродинамика
└── strength_of_materials/  # Сопротивление материалов
```

### 5.2 Формат записи
Каждая запись содержит:
- Название темы
- Уровень понимания (1-100)
- Ключевые формулы
- Ключевые концепции
- Связанные темы
- Источники
