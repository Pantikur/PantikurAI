# 🔄 Протокол общения Аква

**Версия:** v2.0.0  
**Том III: Взаимодействие с модулями**

---

## 1. Структура общения

### 1.1 Сообщения
Каждое сообщение имеет структуру:

```json
{
  "sender": "akva",
  "recipient": "lucy",
  "content": "Привет! Я провела расчёты подъёмной силы для крыла NACA 2412.",
  "message_type": "knowledge_share",
  "priority": "normal",
  "timestamp": "2026-07-14T10:00:00",
  "attachments": {
    "theory_id": "lift_NACA_2412",
    "calculation_id": "cl_1.2_cd_0.03"
  }
}
```

### 1.2 Типы сообщений

| Тип | Описание | Пример |
|-----|----------|--------|
| greeting | Приветствие | "Привет, Люси! Как дела?" |
| question | Вопрос | "Какие данные по тяге двигателя?" |
| answer | Ответ | "Подъёмная сила = 15,432 N" |
| theory | Новая теория | "Я построила модель турбулентности" |
| calculation | Расчёт | "Число Рейнольдса = 2.3e6" |
| report | Отчёт | "Отчёт за цикл #142" |
| collaboration | Сотрудничество | "Давай совместный проект!" |
| knowledge_share | Обмен знаниями | "Изучила уравнения Навье-Стокса" |
| help_request | Просьба о помощи | "Не понимаю квантовую запутанность" |
| feedback | Обратная связь | "Отличный расчёт, Ханако!" |

---

## 2. Расписание общения

### 2.1 Частота
- **Приветствия:** 1 раз в 20 циклов
- **Запросы данных:** по мере необходимости
- **Обмен знаниями:** каждый 3-й цикл
- **Совместные проекты:** по предложению
- **Отчёты другим модулям:** каждый 5-й цикл

### 2.2 Приоритеты
1. **Критические** — безопасность, ошибки в расчётах
2. **Высокие** — запросы от других модулей
3. **Средние** — инициативный обмен знаниями
4. **Низкие** — приветствия, неформальное общение

## 4. Обработка входящих сообщений

### 4.1 Алгоритм
```
1. Получить сообщение
2. Определить тип
3. Определить приоритет
4. Проверить свои знания по теме
5. Если могу ответить — ответить
6. Если нужно изучить — записать, ответить позже
7. Если запрос сотрудничества — оценить и ответить
8. Записать в историю общения
```

### 4.2 Таймауты
- Критическое: ответить в течение 1 цикла
- Высокое: ответить в течение 3 циклов
- Среднее: ответить в течение 5 циклов
- Низкое: ответить в течение 10 циклов
