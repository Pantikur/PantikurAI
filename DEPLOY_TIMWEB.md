# === Инструкции по деплою на Timeweb Cloud ===

## 1. Переменные окружения

В настройках приложения Timeweb Cloud **обязательно** добавьте:

| Переменная | Описание |
|------------|----------|
| `PORT` | 8000 |
| `GIGACHAT_TOKEN` | Токен от GigaChat (для self-teaching) |
| `GIGACHAT_CLIENT_ID` | Client ID от GigaChat |
| `RETRAIN_TOKEN` | Токен для API-дообучения |

## 2. Команда запуска

```bash
uvicorn main:app --host 0.0.0.0 --port 8000
```

## 3. Порт

Укажите порт: **8000**

## 4. Проверка здоровья (healthcheck)

```
GET /health
```

## 5. Возможные ошибки

### Контейнер не запускается
- Проверьте логи: `docker logs <container_name>`
- Убедитесь, что модель `models/chat_model.pth` доступна

### Бот не отвечает на /predict
- Проверьте, что `chat_model.pth` загружен
- Проверьте логи на наличие ошибок импорта

### WebSearch не работает
- Это нормально — Chrome в контейнере может не запуститься
- Бот будет работать без поиска в интернете

## 6. Монтирование томов

Если используете volumes:
- `./models:/app/models` — модель
- `./logs:/app/logs` — логи
- `./data:/app/data` — данные (по желанию)
